# 🎲 Aura RNG (로블록스 RNG 게임)

버튼을 눌러 **오라**를 뽑는 Sol's RNG 스타일의 로블록스 게임입니다. 흔한 오라는 1/2,
가장 희귀한 오라는 **1/100,000,000**. 뽑은 오라는 머리 위 이름표와 파티클로 자랑할 수 있고,
희귀한 걸 뽑으면 서버 전체에 알림이 갑니다.

> 이 저장소(nai-cg-maker)의 `roblox-rng/` 폴더에 들어 있지만 나머지 코드와는 **완전히 독립**된
> 프로젝트입니다. 폴더째 다른 저장소로 옮겨도 그대로 동작합니다.

## 게임 기능

| 기능 | 내용 |
|---|---|
| 굴리기 | 버튼 / **R** 키. 룰렛처럼 이름이 돌다가 멈추는 연출, 등급이 높을수록 길고 화려함(전설↑ 은 한 박자 뜸 + 화면 번쩍) |
| 자동 굴리기 | 버튼 / **T** 키. 흔한 결과는 연출을 짧게 |
| 행운 | 기본 x1. **10번째 굴림마다 행운 x2** (화면에 남은 횟수 표시) |
| 코인 | 굴릴 때마다 획득 (희귀할수록 많이) |
| 상점 | 행운 물약(x1.5), 신속 물약(굴림 속도 +40%), 대박 물약(x3). 서로 다른 물약끼리는 효과가 곱해짐 |
| 가방 | 가진 오라 목록 · 눌러서 장착/해제 · "더 희귀하면 자동 장착" 설정 |
| 도감 | 전체 오라와 확률, 발견 현황 (안 뽑은 건 `???`) |
| 오라 표시 | 머리 위 이름표(그라데이션 오라는 색이 회전) + 희귀 등급부터 파티클, 에픽부터 빛, 신화부터 빛기둥 |
| 서버 알림 | **1/1,000 이상**을 뽑으면 모두에게 배너 + 채팅 알림 |
| 리더보드 | 굴림 횟수, 최고 오라 |
| 저장 | DataStore 자동 저장(2분마다 + 퇴장/서버 종료 시) · 서버 이동 시 데이터 꼬임 방지 세션 잠금 |
| 보안 | 굴림 판정·코인·물약·장착 전부 **서버에서** 처리/검증 (클라가 결과를 조작할 수 없음) |

## 실행 방법

### A. 파일 하나로 바로 열기 (가장 쉬움)

1. 이 폴더의 **`AuraRNG.rbxlx`** 를 내려받습니다.
2. Roblox Studio 에서 **File → Open from File** 로 엽니다.
3. **Play (F5)** 를 누르면 바로 굴릴 수 있습니다.

Studio 에서는 기본적으로 **저장 없이** 플레이됩니다(출력창에 안내가 뜹니다). 저장까지 테스트하려면
게임을 게시한 뒤 **Game Settings → Security → Enable Studio Access to API Services** 를 켜세요.

### B. Rojo 로 코드 동기화 (개발용)

```bash
rojo serve          # Studio 의 Rojo 플러그인에서 Connect
rojo build -o AuraRNG.rbxlx   # place 파일 다시 만들기
```

코드를 고친 뒤에는 `rojo build` 로 `AuraRNG.rbxlx` 를 다시 만들어 주세요(자동으로 갱신되지 않습니다).

### C. 게임에 게시

Studio 에서 **File → Publish to Roblox** 를 하면 끝입니다. 게시 후 실제 서버에서는 저장이 자동으로 켜집니다.

## 조정하기

- **밸런스** (쿨타임, 행운 굴림 주기/배수, 알림 기준, 코인 공식, 물약 가격·효과·시간):
  `src/shared/Config.luau`
- **오라 추가/수정**: `src/shared/Auras.luau` 의 `DEFINITIONS` 에 한 줄 추가
  (`Id, 이름, 영문, N, 색, 그라데이션(선택)`). 등급은 N 으로 자동 결정됩니다.
  ⚠️ `Id` 는 저장 키라서 이미 게시한 뒤에는 바꾸지 마세요.
- **저장 초기화**: `Config.DATASTORE_NAME` 을 바꾸면 새 저장소를 씁니다.

## 구조

```
roblox-rng/
├─ default.project.json      Rojo 프로젝트 (Studio 트리 매핑 + 바닥/스폰/조명)
├─ AuraRNG.rbxlx             rojo build 결과물 (Studio 에서 바로 열기)
├─ src/
│  ├─ shared/  → ReplicatedStorage.Shared
│  │  ├─ Config.luau          밸런스 값
│  │  ├─ Auras.luau           오라/등급 정의
│  │  ├─ RollLogic.luau       굴림 판정 (순수 함수)
│  │  ├─ PlayerState.luau     플레이어 데이터 규칙: 굴림 반영, 물약, 장착, 저장값 정리 (순수 함수)
│  │  ├─ Format.luau          숫자/시간 표시
│  │  └─ Net.luau             RemoteFunction/RemoteEvent 생성·조회
│  ├─ server/  → ServerScriptService.Server
│  │  ├─ init.server.luau     세션, 굴림/상점/장착 원격 처리, 자동 저장, 알림
│  │  ├─ DataService.luau     DataStore + 세션 잠금
│  │  └─ AuraDisplay.luau     머리 위 이름표 + 파티클
│  └─ client/  → StarterPlayerScripts.Client
│     ├─ init.client.luau     상태 동기화, 굴리기 흐름, 입력
│     ├─ Hud.luau             화면(스탯·버튼·연출·알림)
│     ├─ Panels.luau          가방/도감/상점 창
│     └─ Ui.luau              UI 헬퍼, 화면 크기 자동 스케일(모바일 대응)
├─ tests/                     순수 모듈 단위 테스트 + 확률 몬테카를로 검증
└─ tools/luaurun/             테스트용 초소형 Luau 실행기 (Rust)
```

## 테스트

게임 규칙(`src/shared` 의 판정·데이터 로직)은 Roblox 밖에서 테스트합니다. 200만 번 굴려서
실제 분포가 계산한 확률과 맞는지도 확인합니다.

```bash
cargo build --release --manifest-path tools/luaurun/Cargo.toml
./tools/luaurun/target/release/luaurun tests/run.luau
```

서버/클라이언트 코드는 문법 컴파일까지만 자동 확인되므로, 화면·연출은 Studio 에서 Play 로 확인해 주세요.
