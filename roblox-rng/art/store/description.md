# 스토어 설명 (LANDMARK RNG!)

붙여 넣을 글은 [`description.txt`](description.txt)에 있습니다. 그 파일 전체를 Creator Hub의
**설명(Description)** 칸에 그대로 붙여 넣으면 됩니다.

- 형식은 참고한 인기 RNG 게임 스토어 페이지와 같습니다. 이모지로 감싼 환영 줄 한 개, 그 아래에 이모지로 시작하는 짧은 줄들이 옵니다.
  내용은 모두 이 게임 것입니다(다른 게임 이름은 쓰지 않음).
- 한국어를 먼저, 영어를 그 뒤에 씁니다. 한 번 붙여 넣으면 두 언어가 다 보입니다.
- 길이: 글자 872자(UTF-16 896단위, 이모지를 2칸으로 세는 방식). 로블록스 설명 한도 1000자보다 짧습니다.

## 코드와 맞춰 본 내용

| 설명 줄 | 코드 근거 |
|---|---|
| 5대륙 명소 150곳 | `Landmarks.luau` DEFINITIONS 150줄. 대륙 5개: 아시아 34, 유럽 35, 아메리카 32, 아프리카 24, 오세아니아 19 |
| 7개 등급, 1/2 ~ 1/40,000,000 | `Landmarks.Tiers` 7개(일반 명소 ~ 전설). 홍콩 시계탑 `OneIn = 2`, 세계수 `OneIn = 40000000` |
| 전설: 세계수·샹그릴라·무 대륙·용궁·젊음의 샘… | 전설 등급(1/1,000,000 이상) 6개: 젊음의 샘 1/1,000,000, 용궁 1/2,000,000, 무 대륙 1/3,000,000, 사하라 신기루 성 1/5,000,000, 샹그릴라 1/10,000,000, 세계수 1/40,000,000. 한 줄에 다 못 넣어서 "…"로 줄임 |
| 여권 도장마다 영구 행운 +25% | `Config.REGION_LUCK_BONUS = 0.25`. 행운 × (1 + 0.25 × 도장 수). 도장 조건은 그 대륙의 불가사의 등급까지(`STAMP_MAX_RANK = 5`) 모두 발견 |
| 공원에 3D로 배치 | `ParkEdit.luau` 3D 배치 모드(DESIGN.md "공원 배치 (v4)", "3D 배치 모드 (v5)") |
| 업그레이드 4종 | `Config.Upgrades`: 지구본 행운 +10%, 여행사 굴림 간격 -5%, 공원 확장 전시 칸 +3, 입장료 수입 +20% |
| 환생 최대 10번, 행운 +20%, 수입 +50% | `MAX_REBIRTHS = 10`, `REBIRTH_LUCK_BONUS = 0.2`, `REBIRTH_INCOME_BONUS = 0.5` (환생 수만큼 더함) |
| 1/1,000 뉴스 속보, 1/10,000 홀로그램 | `ANNOUNCE_ONE_IN = 1000`, `HOLOGRAM_ONE_IN = 10000` (광장 하늘의 거대 홀로그램) |
| 게임패스 3개 | `Config.GamePasses`: 행운 VIP(행운 ×2), 빠른 굴림(굴림 간격 ×0.7), 수입 2배 |
| 15분 행운 ×2 (나만 / 서버 전체) | `Config.Products`: 행운 부스트 900초 ×2, 서버 행운 900초 ×2 `ServerWide`. 코인 팩도 있지만 짧게 쓰려고 뺌 |
| 서버당 최대 8명 | 광장 둘레 공원 부지 8칸(`ParkService`, DESIGN.md "공원 부지"). README대로 플레이스 Max Players를 8로 해 두었는지 한 번 더 확인 |

### 일부러 바꾼 표현

- **"실제 명소 150곳"이라고 쓰지 않았습니다.** 150곳 안에는 세계수, 샹그릴라, 용궁, 무 대륙, 아틀란티스, 엘도라도,
  바벨탑처럼 전설 속 장소가 들어 있습니다. 그래서 한국어는 "5대륙 명소 150곳", 영어는 "real wonders to lost legends"로 썼습니다.
- 여권 도장은 "대륙 명소를 다 모으면"이라고 쓰지 않았습니다. 도장 조건에는 불가사의 등급까지만 들어가고 잃어버린 유산·전설 등급은
  빠집니다. 그래서 "도장마다 +25%"라고만 썼습니다.
- 확률은 게임 화면처럼 콤마를 넣은 자연수로 적었습니다(1/40,000,000).

## 업데이트 줄

`🆕 v17: 환생 10단계 · 3D 공원 배치 · 상점 오픈!`

- 새 버전을 게시하면 번호와 새 기능만 바꿔 쓰면 됩니다(예: `🆕 v18: …`).
  내용은 바뀌지 않고 번호만 오른 게시라면 이 줄은 그대로 둬도 됩니다.
- 플레이어는 게임 안에서 "v17"이라는 글자를 보지 못합니다. 번호가 헷갈릴 것 같으면 `🆕 업데이트:`로 바꿔도 됩니다.

## 추천 장르

- **시뮬레이션(Simulation)**
  - 하위 장르 1순위: **Incremental Simulator(증분 시뮬레이터)**. 굴리기·수집·환생이 이어지는 RNG 게임이 주로 여기에 들어갑니다.
  - 2순위: **Tycoon(타이쿤)**. 공원 전시·관광 수입 쪽을 앞세우고 싶을 때 고릅니다.
- 하위 장르 이름은 Creator Hub 드롭다운에 보이는 이름을 기준으로 골라 주세요. 목록은 가끔 바뀝니다.

## 참고

- 로블록스는 설명 글을 필터에 거칩니다. 게시 뒤 스토어 페이지에서 숫자나 글자가 `###`으로 가려지지 않았는지 확인해 주세요.
- 로블록스는 언어별 설명을 따로 넣을 수 있습니다(Localization). 나중에 둘로 나누려면 빈 줄 기준으로 위(한국어)와
  아래(영어)를 잘라 각 언어 칸에 넣으면 됩니다.
- 이모지는 스토어 페이지에서만 씁니다. 게임 안 UI에는 쓰지 않습니다.
