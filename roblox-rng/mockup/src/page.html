랜드마크 RNG — 새 UI 미리보기

로블록스에 올리기 전 시안입니다. src/client 의 Ui / Hud / Panels 코드와 같은 크기·색·글자로 그렸고, art/png 그림이 모두 올라가 ImageIds 가 채워진 상태(그림 버전)를 가정했습니다.

  • 3D 모형 자리: 게임에서는 명소 3D 모형(ViewportFrame)이 들어가는 칸 — 여기선 이름 첫 글자로 대신함
  • 화면 1280×720, 게임 코드의 자동 배율 0.9(Ui.autoScale 최대값) 적용(1-2~1-4 · 3-2 · 4-2 는 태블릿 1024×768·휴대폰 667×375/844×390 에서 그 크기의 배율로), 위쪽 58px 는 로블록스 기본 상단바 자리(흐리게 표시)
  • 한글은 FredokaOne·LuckiestGuy 에 글자가 없어서 로블록스가 대체 글꼴(Noto Sans CJK)로 그립니다. 두 글꼴 모두 보통(Regular) 굵기로 등록돼 있어 한글도 보통 굵기로 나온다고 보고 Noto Sans KR Regular 로 표시 — 명소 공개의 큰 이름·"속보"도 둥근 만화 글꼴이 아니라 이 한글 글꼴 + 굵은 테두리로 나옵니다(실제 굵기는 엔진 버전에 따라 조금 다를 수 있음)
  • 제목 리본(Ui.ribbon)은 코드로 그린 판 + V 꼬리 그림(ribbon_tail_l/r) 버전. 꼬리 그림을 아직 안 올려 ImageIds 가 비어 있으면 게임에서는 둥근 네모 Frame 꼬리가 나오는데, 주소 끝에 ?tails=frame 을 붙이면 그 모양으로 그립니다
  • 뒤 배경(하늘·광장·지구본·캐릭터)은 게임 3D 월드 자리를 흉내 낸 그림일 뿐, UI 코드가 그리는 것이 아님. 로블록스가 따로 그리는 오른쪽 위 순위표(leaderstats "굴림/최고")는 그리지 않음
