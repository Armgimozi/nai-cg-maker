# 아오오니 저택 서버팩 (4~6인)

잉여맨의 "아오오니 저택" 술래잡기를 바탕으로 만든 **팬메이드 마인크래프트 서버팩**입니다.
**한 명이 아오오니(술래)**, 나머지는 생존자입니다. 생존자는 저택의 상자를 뒤져 **비밀번호 쪽지 4장**을 찾고,
금고에서 **마검** 하나를 꺼내 **아오오니를 족치면** 이깁니다. 아오오니는 생존자를 모두 쓰러뜨리면 이깁니다.

원본 맵 파일을 복제한 것이 아니라, 저택과 규칙을 데이터팩 명령어로 처음부터 새로 만들었습니다.
**바닐라 서버 + 데이터팩 + 리소스팩**(아오오니 모델과 마검 모양)으로 동작하며, 모드는 필요 없습니다.

- 인원: **4~6명 권장** (최소 2명: 아오오니 1명 + 생존자)
- 지원 버전: **Java 에디션 1.21.5 ~ 26.3** (기본값 1.21.11)

## 빠른 시작 (Windows)

1. `dist/aooni-mansion-serverpack.zip` 을 받아 원하는 폴더에 압축을 풉니다.
2. Java 를 설치합니다. 1.21.x 는 **Java 21**, 26.x 는 **Java 25 이상** ([adoptium.net](https://adoptium.net)).
3. `start.bat` 을 더블클릭합니다.
   - 처음 실행하면 Mojang 공식 서버에서 `server.jar` 를 자동으로 받습니다.
   - [Minecraft EULA](https://aka.ms/MinecraftEULA) 동의 여부를 묻습니다. `Y` 를 입력하면 시작합니다.
4. **모든 참가자**가 `dist/aooni-resourcepack.zip` 을 마인크래프트의 `resourcepacks` 폴더에 넣고
   (옵션 → 리소스 팩 → 팩 폴더 열기) 켜 줍니다. 안 켜면 아오오니와 마검이 보라·검정 체크무늬로 보입니다.
5. 마인크래프트 런처에서 같은 버전(기본 1.21.11)을 실행해 `localhost` 로 접속합니다.
6. 친구들은 `내 IP:25565` 로 접속합니다. 공유기 포트포워딩(25565)이나 Radmin VPN/Hamachi 같은 가상 LAN 을 쓰세요.

Linux/macOS 는 `./start.sh` 를 실행하면 됩니다. 다른 버전을 쓰려면 `start.bat` 의
`set MC_VERSION=1.21.11` 을 고치거나 `MC_VERSION=26.3 ./start.sh` 처럼 실행하세요.

> 처음 서버가 켜지면 몇 초 뒤 채팅에 "저택과 대기실을 지었습니다" 가 뜹니다. 그 전에 접속해도 괜찮습니다.

## 기존 서버·싱글플레이에 넣기

- 데이터팩만 필요하면 `dist/aooni-mansion-datapack.zip` 을 월드의 `datapacks` 폴더에 넣고 `/reload` 하세요.
- **평지(Superflat) 월드**를 권장합니다. 저택(정원 포함)은 좌표 `x -5~60, z -5~60, y -61~-29` 에,
  대기실은 `x -30~-12, z 2~22` 에 지어지며, 그 자리에 있던 블록은 지워집니다.
- 아오오니가 생존자를 때리는 방식이라 **PvP 가 켜져 있어야** 합니다(`server.properties` 의 `pvp=true`, 1.21.11 이상은 게임룰 `pvp` 도 자동으로 켭니다).
- 크리에이티브 모드인 사람은 게임 참가자에서 빠집니다(관리자 관전용). 참가하려면 모험/서바이벌 모드로 바꾸세요.

## 저택

지하 1층과 지상 3층, 방 32개짜리 저택입니다. 층마다 십자 모양 복도가 있고, 계단은 두 갈래가 층마다 번갈아 놓여 있어서
쫓기면서 빙 돌아 도망칠 수 있습니다. 1층 현관홀에는 2층으로 가는 큰 계단이 있습니다.

- **1층 현관홀**: 생존자가 시작하는 곳. 현관문은 아오오니를 쓰러뜨려야 열립니다.
- **지하 감옥**: 쓰러진 생존자가 부활하는 곳
- **2층 창고**: 마검 금고
- **3층**: 아오오니가 깨어나는 곳

## 게임 방법

### 대기실
- **[아오오니 지원]**: 아오오니를 하고 싶은 사람이 누릅니다. 지원자 중 무작위 1명이 아오오니가 되고, 지원자가 없으면 전체 중 무작위입니다.
- **[난이도 변경]**, **[규칙 보기]**, **[게임 시작]** (카운트다운 5초)
- 양쪽 끝의 **[혼자 연습]** 버튼 2개: 아래 "혼자 테스트하기" 참고

### 생존자
| 조작 | 설명 |
|---|---|
| 상자 (저택 곳곳 63개) | 열어서 뒤집니다. 판마다 내용물이 바뀝니다 (아래 표) |
| 2층 창고 금고 (다이얼 4개 + 확인) | 다이얼을 눌러 숫자를 맞추고 확인. 맞으면 **마검**이 나옵니다. 틀리면 금속음과 함께 5초간 몸이 빛나 위치가 드러납니다 |
| 옷장 (가문비나무 문, 32개) | 들어가서 **문을 닫으면 완전히 안전**합니다. 아오오니는 문을 절대 열 수 없고, 옷장 안에서 기다리고 있어도 문이 닫히면 밖으로 밀려납니다 |
| 감옥 앞방의 버튼 | 갇힌 동료를 감옥 앞으로 꺼내 줍니다 (20초 재사용 대기, 풀려난 사람은 5초 무적). 감옥 철문 자체는 열리지 않습니다 |

**체력과 감옥**
- 아오오니에게 맞으면 체력이 깎입니다. 쉬움 5대 · 보통 4대 · 어려움 3대에 쓰러집니다.
- 쓰러지면 **지하 감옥에서 부활**하고 목숨이 하나 줄어듭니다. 목숨을 모두 잃으면 관전 모드가 됩니다.
- 체력은 저절로 차지 않습니다. 상자에서 찾은 **음식과 물약**으로만 회복됩니다.
- 아오오니가 가까이 오면 심장 소리가 나고 화면이 어두워집니다.

**상자에서 나오는 것**
| 종류 | 아이템 |
|---|---|
| 비밀번호 쪽지 ①~④ | 접혀 있어서 집어야 숫자가 보입니다. 처음 집은 순간 그 숫자가 생존자 모두의 채팅에 나옵니다(아오오니에게는 안 보임) |
| 가짜 쪽지 (3장) | 진짜와 똑같이 생겼지만, 집어서 펼쳐 보면 글씨가 번져 있습니다 |
| 회복 | 빵(체력 2칸), 스테이크(4칸), 회복 물약(4칸 즉시), 황금 사과. 빵과 스테이크는 배가 불러도 먹을 수 있습니다 |
| 도망·방해 | 엔더 진주(던진 곳으로 순간이동), 구속 물약·실명 물약(아오오니에게 던지기), 신속·투명·야간 투시 물약 |
| 잡동사니 | 낡은 인형, 깨진 접시, 멈춘 시계 같은 꽝 아이템 |

- **움직일 수 있는 생존자가 전부 옷장에 숨으면** 40초에 경고가 뜨고, 60초가 되면 저택의 모든 옷장 문이 저절로 열립니다
  (판이 영원히 끝나지 않는 것을 막는 장치입니다. 한 명이라도 밖에 있으면 일어나지 않습니다). 아오오니가 옷장을 여는 일은 없습니다.
- **마검**: 지닌 사람만 힘 V(한 방 약 23)를 얻습니다. 마검이 없으면 맨손 피해가 0입니다.
  마검을 든 사람이 쓰러지면 **그 자리에 떨어집니다**(반짝임). 다른 사람이 주워 이어서 싸우세요. Q 로 건네줄 수도 있습니다.
  떨어진 마검은 사라지지 않고, 상자에 넣어 숨길 수도 없습니다. 마검이 어디에도 없으면 10초 뒤 저택 어딘가에 다시 나타납니다.

### 아오오니
- 시작 후 **20초 동안 3층에 묶여** 있다가 깨어납니다. 투명한 몸 대신 아오오니 모형이 걸어 다닙니다(리소스팩 필요).
- 생존자를 때려 쓰러뜨립니다. 어둠 속에서도 잘 보이고, 난이도에 따라 빨라집니다.
- **문·버튼·옷장·상자를 전혀 만질 수 없습니다.** 감옥 버튼도, 금고도 못 누릅니다.
  마검을 주우면 손에서 튕겨 나가 먼 곳에 다시 나타나고, 쪽지를 주우면 원래 상자로 돌아갑니다.
- 화면 아래에 남은 생존자 수가 보입니다.

### 결전과 승패
- 마검이 나오면 아오오니가 **1.3배로 커지고** 체력바가 뜹니다. 체력은 `60 + 생존자 수 × 20` 입니다(생존자 4명이면 140).
  절반 아래로 떨어지면 격노해서 더 빨라집니다. 커진 아오오니도 모든 방과 계단을 지나갈 수 있습니다.
- **아오오니 체력 0 → 생존자 승리**(현관문이 열립니다), **움직일 수 있는 생존자 0명 → 아오오니 승리**.
  (마지막 생존자가 접속이 끊긴 경우는 20초 기다립니다.)
- 아오오니가 접속을 끊고 30초 안에 돌아오지 않으면, 결전 중이면 생존자 승리, 결전 전이면 게임이 중단됩니다.
- 게임 도중 크리에이티브 모드로 바꾼 사람은 역할에서 빠집니다.
- 끝나면 대기실로 돌아가고, 다음 판 시작 때 저택이 새로 지어집니다. 상자 내용물은 판마다 바뀝니다.

### 난이도

| | 쉬움 | 보통 | 어려움 |
|---|---|---|---|
| 몇 대 맞으면 쓰러지나 | 5 | 4 | 3 |
| 생존자 목숨 | 4 | 3 | 2 |
| 아오오니 속도 | 기본 | 신속 I | 신속 II |

## 혼자 테스트하기

실전은 최소 2명이 필요하지만, 혼자 접속해 있을 때는 대기실 양쪽 끝 버튼으로 미리 해 볼 수 있습니다. OP 권한은 필요 없습니다.

| 버튼 | 내용 |
|---|---|
| **혼자 연습 (생존자)** (오른쪽 끝, 하늘색) | 내가 생존자가 됩니다. 아오오니 없이 저택을 둘러보며 상자를 열고, 쪽지 4장으로 금고를 풀어 마검을 꺼내는 데까지 해 볼 수 있습니다. 마검을 꺼내면 연습이 끝납니다 |
| **혼자 연습 (아오오니)** (왼쪽 끝, 보라색) | 내가 아오오니가 됩니다. 생존자가 없어서 승패는 나지 않습니다. 모형, 걷는 동작, 문·버튼·옷장을 못 만지는 것을 확인해 보세요 |

- 끝내려면 채팅에 `/trigger aooni.quit` 을 입력합니다.
- OP 라면 인원과 상관없이 `/function aooni:admin/solo`(생존자 연습), `/function aooni:admin/solo_oni`(실행한 사람이 아오오니)도 쓸 수 있습니다.

## 관리자 명령 (OP)

| 명령 | 설명 |
|---|---|
| `/function aooni:admin/help` | 명령 목록 |
| `/function aooni:admin/start` | 카운트다운 없이 바로 시작 |
| `/function aooni:admin/stop` | 게임 중단 후 대기실로 |
| `/function aooni:admin/rebuild` | 저택·대기실 다시 짓기 (게임 중이면 끝난 뒤에) |
| `/function aooni:admin/difficulty_1` (`_2`, `_3`) | 난이도 쉬움/보통/어려움 |
| `/execute as 닉네임 run function aooni:admin/oni_pick` | 다음 판 아오오니 지정 |
| `/function aooni:admin/final_now` | 테스트용: 생존자 한 명에게 마검을 주고 바로 결전 |
| `/function aooni:admin/solo` | 생존자 연습 (모험 모드인 사람 모두 생존자, 아오오니 없음) |
| `/function aooni:admin/solo_oni` | 아오오니 연습 (실행한 사람이 아오오니, 승패 없음) |
| `/trigger aooni.quit` | 연습 끝내기 (누구나) |

OP 권한은 서버 콘솔에 `op 닉네임` 을 입력해서 줄 수 있습니다.

## 문제 해결

- **저택이 안 생겨요**: `/datapack list` 에 `file/aooni_mansion` 이 켜져 있는지 확인하고 `/function aooni:admin/rebuild` 를 실행하세요.
- **아오오니와 마검이 보라·검정 체크무늬예요**: 리소스팩(`dist/aooni-resourcepack.zip`)을 켜지 않은 경우입니다.
- **아오오니가 때려도 피가 안 닳아요**: PvP 가 꺼져 있는 경우입니다. `server.properties` 의 `pvp=true` 를 확인하세요.
- **"호환되지 않는 데이터팩" 경고**: 1.21.5 미만이나 26.3 보다 새 버전에서 나타납니다. 1.21.5 ~ 26.3 을 쓰세요.

## 직접 고치기 (개발자용)

데이터팩은 `tools/build_pack.py` 가 자동으로 만듭니다. 저택 구조, 규칙, 대사, 수치를 이 파일에서 고친 뒤 다시 생성하세요.

```bash
python3 tools/build_pack.py          # 데이터팩 + 배포 zip 생성, 구조 점검, 명령어 검사
python3 tools/build_pack.py --map    # 층별 평면도(텍스트)도 출력
```

`tools/mcvalidate.py` 는 Mojang 의 버전별 명령어 트리(misode/mcmeta)를 내려받아 모든 명령 줄을
1.21.5, 1.21.8, 1.21.11, 26.1.2, 26.2, 26.3 기준으로 파싱해 봅니다. 그리고 저택 구조를 BFS 로 점검해,
모든 방에 실제로 갈 수 있는지(거대 아오오니 포함), 상자마다 다가갈 수 있는지, 감옥과 현관문이 제대로 막혀 있는지 확인합니다.
