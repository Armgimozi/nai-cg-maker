# 블록수선전

웹소설 **회귀수선전**의 수선 경지 체계(경지·단계 이름, 천겁, 영맥)를 바탕으로 한 로블록스 수선 시뮬레이터.
세계(옥반)와 땅 이름은 게임에서 새로 지었다. 회귀·종명자 요소는 넣지 않았다.

## 플레이

| 조작 | 키 | 하는 일 |
| --- | --- | --- |
| 운기조식 | `R` | 제자리에 앉아 영기를 모은다. 움직이거나 뛰면 풀린다. |
| 돌파 | `B` | 경지의 마지막 단계에서 영력과 과업을 다 채우면 다음 경지로 넘어간다. |
| 상태창 | `C` | 경지·능력치와 익힌 술법·공법을 보고, 공법 장착·술법 단축칸·단축키를 정한다. |
| 술법 | `Q` `E` `Z` `X` (바꿀 수 있음) | 단축칸에 넣은 술법을 쓴다. 화면 아래 칸을 눌러도 된다. |
| 채집 | `F` (길게) | 영초를 먹거나 비급을 주워 익힌다. |
| 공격 법구 | `1`~`9` | 지닌 공격 법구를 든다 (Roblox 기본 도구 칸). |
| 공격 | 클릭 (터치) | 든 공격 법구로 앞쪽 요수를 벤다. 부채는 기운을 날린다. |

상태창의 "단축키" 줄에서 칸을 누르고 원하는 키를 누르면 바뀐다 (Q E T Y U G H J K L Z X V N P 중에서).
술법 줄의 작은 키 버튼으로 어느 칸에 넣을지 고른다. 새로 익힌 술법은 빈 칸에 저절로 들어간다.

- 영력은 연료이고, 다음 단계로 가는 열쇠는 그 단계의 **과업**이다. 과업은 화면 왼쪽 영력 막대 아래에 보인다.
  과업 줄을 누르면 할 일을 화면 위 알림으로 다시 알려 준다. 영력과 과업을 다 채우면 같은 경지 안에서는 저절로 오른다.
- 범인: 운기조식 30초로 영기를 느끼고, **영근**을 고르고, 영초를 하나 먹는다. 영근은 오행 중 **한 속성**만 지닌다
  (천영근은 내관을 건너뛸 수 있고, 홍삼을 먹으면 홍영근이 된다).
- 단수기: 내 영근 속성의 **오행처**를 돌며 운기하고(오행지의), 음양 박자(음양지의), 농도 막대(혼원지의) 내관을 한다.
- 내관(미니게임)은 과업 줄의 "내관" 버튼으로 연다. 천·진영근은 "건너뛰기"로 영력을 2.5배 내고 퍼즐을 넘길 수 있다(선통후각).
- 서버 공용 **낮밤**이 12분마다 돈다 (낮 7분, 밤 4분). 밤에만 하는 과업이 있다.
- 천겁은 원작대로 **원영기부터** 내린다. 원영기 1·2·3·4줄기, 천인기 5·10·15·20줄기.
  쓰러지거나 도중에 나가면 실패: 경지는 그대로, 영력 일부를 잃는다. 피해는 천겁을 맞는 본인에게만 들어간다.
- 연기기 14성은 성마다 할 일이 다르다.

  | 성 | 하는 일 |
  | --- | --- |
  | 1 칠십이지살 | 빛나는 맥의 순서를 기억해 짚는다 (9맥씩 8번) |
  | 2 삼십육천강 | 천괴~천교, 천강 별 이름 순서 기억 |
  | 3 십이지율 | 광장 네 귀퉁이 율점 등롱 12곳 곁에서 취령진을 펴고 운기 (취령진이 없으면 기초본을 준다) |
  | 4 십천간도 | 오행처 다섯 곳을 낮에 한 번(양간), 밤에 한 번(음간) |
  | 5 구궁귀일 | 구궁판 패를 맞바꿔 가로·세로·대각선 합 15 |
  | 6 팔괘완로 | 관성대 팔괘 기둥을 건 태 리 진 손 감 간 곤 순서로 F |
  | 7 칠성제의 | 칠수 고르기, 칠성단에 영초 7 바치기, 밤 시운에 제의를 올려 푸른 원으로 별빛 다섯 줄기 받기 |
  | 8 육합만로 | 사방 성대, 관운봉 꼭대기, 벽담 너럭바위에서 운기 |
  | 9 오행진의 | 본명 속성을 골라 그 오행처에서 운기 |
  | 10 사상이의 | 낮에 20초, 밤에 20초 운기 |
  | 11 삼재규일 | 벽담 너럭바위, 광장, 관운봉 꼭대기 순서로 운기 |
  | 12 이의합일 | 음양 박자를 끊기지 않고 24번 |
  | 13 일원일응 | 줄어드는 고리를 점에 세 번 잇달아 맞추기 |
  | 14 무극영운 | B 로 단전을 터뜨려 가닥(영근 속성 수의 제곱)을 시간 안에 모두 붙잡는다. 연단로에서 영초 6, 천년영지 1로 축기단을 빚어 두면 쉽다. 실패하면 영력 40%를 잃는다 |
- 축기기: 별 스물여덟 개(각수성~진수성)를 하나씩 맺는다. 밤마다 **영성우**가 내려 푸른 원 자리에 별씨가 박힌다(F 로 줍기).
  별마다 별씨 하나로 "응결" 내관(줄어드는 고리)을 한다. 수의 마지막 별은 그 방위 성대(1수 동, 2수 북, 3수 서, 4수 남)에서
  밤에 자리를 잡고 별자리를 긋는다. 제사한 칠수의 수에서는 별씨가 반만 들고 영력도 덜 든다. 3·4수는 영력이 더 든다.
  수를 하나 완성할 때마다 **정순지력**으로 최대 체력 +5%, 천겁 피해 -5%.
  진수성에서는 사방 성대를 도는 재제의와 천구도를 마친 뒤 B 로 **금단 응결**(천·지·인 농도 막대)을 한다.
- 결단기: 천시원(광장 운기, 기혈 정돈), 태미원(칠성단 낮과 밤 제의), 자미원(밤 관운봉 꼭대기, 별 잇기), 천상열차분야(밤 제의 별빛).
  결단기에 들면 경신술이 **비둔술**로 바뀌고, 자미원을 새기면 쓰러져도 10분에 한 번 그 자리에서 일어난다(**금단 재생**).
- 원영기 진입: B 를 누르면 **주마등**이 흐른다. 수행 일지의 기억을 최근 것부터 "송계 마을에 처음 온 날"까지 거슬러 짚으면
  원영이 맺히고, 이어서 첫 **금색 천겁**(예고가 따라오다 멈추는 거대 금뢰 1줄기)이 내린다. 원영기에 들면 **허공이동**을 얻는다.
- 원영기: 여월지긍(밤 벽담 너럭바위), 여일지승(새벽 동쪽 성대, 새벽은 30초뿐), 여오악지수(오악 중심 고르기, 오행처 다섯 곳.
  내 영근에 없는 속성은 오래 걸린다), 불건불붕(일월오악도, 도심 고르기). 단계마다 금색 천겁 2·3·4줄기.
- 천인기 진입: 천겁 다섯 줄기. 들면 **천기유도**(오악 중심 속성의 천지 현상)를 얻는다.
- 천인기: 고른 **도심**(채약, 진법, 연단, 천문, 좌관)에 몰입할 때만 **광기**가 찬다. 사계를 따라
  봄(목 오행처), 여름(화 오행처, 이립에서 **원영 출규**), 가을과 겨울(마을 노인 셋의 마지막 부탁, 종심), 천원(하루를 한 바퀴).
  지천명부터 천겁 예고를 조금 일찍 본다(예지). 단계마다 천겁 10·15·20줄기. 천원이 지금 오를 수 있는 끝이다.
- **영맥** 위에서 운기조식하면 흡수가 빨라진다. 경지와 상관없이 누구나 쓴다. 하품(송계 광장, 마령채, 녹주, 백사포 해신당, x1.5) ·
  중품(청송림 영천굴, 운곡 석종굴, 명경호 경심정, 청음암, 무명사 옛터, x2.5) · 상품(관운봉 꼭대기, 빙경담, 주염산 화구, 침사국 옛터, x4) ·
  극품(청허경, x5).
- 땅마다(송계 둘레, 청송림, 백령, 북쪽 호수·설원·초원, 동쪽 숲, 남쪽, 황구·한해, 청허경) **비급**이 나타난다. 주우면 술법이나 공법을 익힌다.
  비급마다 이해할 수 있는 최소 경지가 있어서, 경지가 모자라면 그대로 남는다.

### 종족

처음 들어오면 게임에서 만든 종족 여덟 가운데 하나가 뽑힌다. 상태창(`C`)에서 내 종족과 효과를 보고,
"확률 보기"로 뽑힐 확률을 먼저 본 뒤 **49 로벅스**로 다시 뽑을 수 있다 (지금 종족은 빼고 뽑는다).
유료 무작위 아이템이 막힌 나라(PolicyService)에서는 다시 뽑기 버튼이 보이지 않는다.

| 종족 | 확률 | 효과 |
| --- | --- | --- |
| 인족 | 34% | 영초 영력 +20%, 영초 하나 더 10% |
| 석령족 | 16% | 체력 +20%, 천겁 피해 -12%, 걸음 -7% |
| 우인족 | 15% | 걸음 +12%, 도약 +30% |
| 염린족 | 12% | 공격 +20%, 체력 +5% |
| 월영족 | 10% | 밤 흡수 +30% |
| 청림족 | 8% | 흡수 +5%, 영초 하나 더 35% |
| 성휘족 | 4% | 흡수 +12%, 내관 판정 +15% |
| 용맥족 | 1% | 흡수 +15%, 체력 +15%, 공격 +15%, 천겁 피해 -10% |

다시 뽑기는 개발자 상품이다. Creator Hub 에서 만든 상품 id 를 [`src/shared/Races.luau`](src/shared/Races.luau)의
`REROLL_PRODUCT_ID` 에 넣는다 (0 이면 버튼이 "준비 중"을 알린다). 영수증은 PurchaseId 를 저장한 뒤에만 지급 완료로 돌려준다.

### 요수와 전투

마을 같은 안전한 땅 밖으로 나가면 땅의 위험도(1~5)에 맞는 **요수**가 나타나 쫓아온다. 요수가 덤비기 전에
발밑에 붉은 원이 보인다. 원 밖으로 피하거나 호신강기로 막는다. 쓰러뜨리면 **요단**(영력)과 가끔 법구를 얻는다.

- 장비는 모두 **법구**다.
- 공격 법구: 검(빠르고 넓게), 도(느리지만 무겁게), 창(멀리 찌르기), 선(기운을 날린다). 등급 목·철·청강·영·천. 대장간에서 강화한다.
- 방어 법구: 부위 구분 없이 **하나만** 지닌다 (상태창 C 의 법구 칸에서 지니기). 겉모습은 없고 효과만 있다.
  호신옥패(받는 피해↓), 금강팔찌(체력↑), 현무갑의(피해 크게↓, 걸음↓), 청운잠(천겁 피해↓), 진령방울(호신강기 지속↑),
  회춘환(맞지 않으면 회복), 반탄경(피해 되돌림), 질풍띠(걸음↑). 등급 범품·하품·중품·상품·극품 ([`src/shared/Guards.luau`](src/shared/Guards.luau)).
  대장간에서 영석과 재료로 만들고, 요수가 떨어뜨리고, 만물상이 범품을 판다.
  처음에는 목검을 지닌다. 요수 위험도와 같은 등급이 떨어진다.
- 요수 여덟: 잿빛이리, 가시멧돼지(1) · 청린사(2) · 바위곰, 적염조, 황사갈(3) · 석장군(4) · 은미호(5).
- 요수와 공격 법구 모양은 Meshy 로 만든 모델이다 ([`tools/meshy`](tools/meshy)). 네 발 짐승은 뼈를 넣어
  클라이언트가 걸음을 움직인다 ([`src/client/MobAnimator.luau`](src/client/MobAnimator.luau)).
  모델을 못 불러오면 블록 모양으로 짓는다.

### 술법과 공법

| 종류 | 이름 | 효과 | 익힐 수 있는 경지 |
| --- | --- | --- | --- |
| 술법 | 경신술 | 보는 방향으로 몸을 날린다 (쿨타임 5초) | 범인 |
| 술법 | 영안 | 12초 동안 영초와 비급이 벽 너머로 보인다 (30초) | 단수기 |
| 술법 | 취령진 | 15초 동안 진 안에서 운기조식하면 흡수 두 배 (30초) | 연기기 |
| 술법 | 호신강기 | 3초 동안 천겁 낙뢰를 막는다 (25초) | 축기기 |
| 술법 | 허공이동 | 보는 방향으로 순간이동 (15초) | 원영기에 들면 얻는다 |
| 술법 | 원영 출규 | 원영이 가까운 영초를 대신 캔다 (40초) | 천인기 이립에서 얻는다 |
| 술법 | 천기유도 | 오악 중심 속성의 현상: 수 영초, 목 천년영지, 토 비급, 화 둘레 영력, 금 영물 끌어오기 (300초) | 천인기에 들면 얻는다 |
| 공법 | 토납법 | 운기조식 흡수 +30% | 범인 |
| 공법 | 백초경 | 영초에서 얻는 영력 +60% | 범인 |
| 공법 | 청심결 | 내관 판정 폭 +20%, 실패 손실 절반 | 단수기 |
| 공법 | 금강체 | 최대 체력 +40% | 연기기 |
| 공법 | 피뢰결 | 천겁 낙뢰 피해 -30% | 결단기 |
| 공법 | 천기감응 | 천겁 낙뢰와 제의 별빛 예고 +0.4초 | 결단기 |

공법 장착 칸은 처음 1칸, 연기기 2칸, 결단기 3칸. 수치와 목록은 [`src/shared/Skills.luau`](src/shared/Skills.luau) 에서 바꾼다.

### 경지 (범인~천인기)

| 경지 | 단계 | 다음 경지로 |
| --- | --- | --- |
| 범인 | 1 | B |
| 단수기 | 1 | B |
| 연기기 | 1성 칠십이지살 ~ 14성 무극영운 | 무극영운 내관 (변화 가닥 붙잡기, 축기단이 있으면 쉽다) |
| 축기기 | 각수성 ~ 진수성 (28별) | 금단 응결 내관 |
| 결단기 | 천시원, 태미원, 자미원, 천상열차분야 | 주마등, 금색 천겁 1줄기 |
| 원영기 | 여월지긍, 여일지승, 여오악지수, 불건불붕 (단계마다 천겁 2·3·4줄기) | 천겁 5줄기 |
| 천인기 | 지선과 이립, 불혹과 지천명, 천순과 종심, 천원 (단계마다 천겁 10·15·20줄기) | 끝 |

경지·단계 이름은 나무위키의 회귀수선전 설정 문서를 따랐다. 영근 고르기 절차, 시간 수치, 미니게임 형식은 게임 규칙이다.
경지는 [`src/shared/Realms.luau`](src/shared/Realms.luau), 단계별 과업은 [`src/shared/Tasks.luau`](src/shared/Tasks.luau),
영근은 [`src/shared/Roots.luau`](src/shared/Roots.luau) 에서 고친다.

### 마을 사람

노인 셋(늙은 약초꾼, 늙은 대장장이, 늙은 뱃사공)은 자리에 앉아 있고, 마을 사람 넷(약초 캐는 청년, 바구니 든 아낙,
마을 아이, 떠돌이 수도자)은 길을 오간다. 가까이 가면 고개를 돌려 보고, F 로 말을 걸면 말풍선으로 이야기한다
(말을 건 사람에게만 보인다). 노인들은 천인기 "천순과 종심"에서 마지막 부탁을 한다.
생김새(카탈로그 아이템), 자리, 동선, 대사는 [`src/shared/Npcs.luau`](src/shared/Npcs.luau), 띄우는 코드는
[`src/server/Villagers.luau`](src/server/Villagers.luau). 아이템을 못 불러오면 옷만, 그것도 안 되면 맨몸으로 선다.

### 맵: 옥반(玉盤)

게임에서 새로 지은 세계다 (땅 이름은 모두 게임에서 지었다). 반지름 1720 남짓의 둥글고 넓은 땅을 바다(환해)가 두르고,
반지름 2240 의 바다 끝(**천애**)에서 물이 운해로 쏟아진다. 천애 너머에는 아무것도 없다. 너무 멀리 헤엄치면 해류가
밀어내고, 떨어지면 가까운 전송진 곁에서 깨어난다 ([`src/server/Edge.luau`](src/server/Edge.luau)). 북쪽이 −z, 동쪽이 +x.
가운데 송계 마을에서 멀어질수록 요수가 사납다. 위험도는 거리 고리(170·560·900·1250·1600)와 땅마다 정한 바닥값 가운데 큰 쪽이고,
마을(0)에는 요수가 들어오지 않는다.

(송계 진은 처음부터 열려 있고 송계로 돌아가는 길은 공짜). 예전 기록의 진 id 는 `Progression.OLD_WAYPOINTS` 가 새 진으로 옮긴다.

땅 모양은 [`src/shared/Land.luau`](src/shared/Land.luau) 한 곳에 있다. 맵을 구울 때 이 모양대로 지형을 플레이스에 넣고
(SmoothGrid, [`tools/SmoothGrid.luau`](tools/SmoothGrid.luau)), 집과 자리는 같은 높이에 놓는다.
엔진이 구운 지형을 못 읽으면 서버가 같은 모양으로 지형을 짓는다([`src/server/TerrainGen.luau`](src/server/TerrainGen.luau), 천애 바깥 묶음은 건너뛴다).
Studio 에서 지형을 손으로 고쳐도 다음 굽기에서 덮이므로 땅은 `Land.luau` 를 고친다. 위에서 본 지도는
`lune run tools/render_map` 이 `build/map.png` 로 그린다.

맵 짓기: [`World.luau`](src/server/World.luau) 가 송계 마을·벽계·청송림과 모든 자리(과업 자리, 오행처, 사방 성대, 칠성단,
전송진, 영맥, 영초 범위, 비급 자리)를 놓고, 땅마다의 모듈(`WorldNorth`, `WorldMountains`, `WorldEast`, `WorldSouth`,
`WorldWest`, `WorldSea`)을 차례로 부른다. 자리 좌표는 [`WorldSites.luau`](src/server/WorldSites.luau) 한 곳에 있고,
땅 모듈은 그 둘레(전송진 9, 과업 자리·영맥 7)를 비워 둔다. 짓는 도구는 `WorldBuild.luau`(지붕·집·나무·성벽 등)와
`WorldKit.luau`(높이 맞추기, 현판, 영맥 못, 전송진). 땅 하나만 미리 보려면
`lune run tools/region_preview <모듈> <x> <z> <반지름>` 뒤 `tools/preview/preview.py` 로 그린다.
스크립트는 이름이 아니라 **태그**로 맵을 찾는다: `Ground`, `Vein`(속성 `VeinId`, `Radius`), `HerbZone`(`RareMult`, `Weight`),
`ManualSpot`, `Site`(속성 `Site`, `Radius`), `Waypoint`(속성 `WaypointId`, `Name`, `Order`), `Plaque`, `MarketSpot`.

맵에는 공중에 뜨는 이름표가 없다. 자리 이름은 땅에 박은 나무 현판과 돌 비석에 붓글씨로 새긴다
(맵은 판에 `Plaque` 태그와 `Text` 속성만 달고, 글자는 [`src/client/Plaques.luau`](src/client/Plaques.luau)가 새긴다).
다른 땅에 들어서면 화면 위쪽에 그 땅 이름이 잠깐 뜨고, 상태 창에 지금 있는 곳이 나온다
(땅 경계와 위험도는 [`src/shared/Places.luau`](src/shared/Places.luau)). 마을 사람 이름은 다가가면 말 걸기 버튼에 뜬다.

## 검수 명령 (플레이스 주인 계정과 Studio 에서만)

채팅창에 친다. 다른 사람이 치면 "주인만 쓴다"는 알림만 가고 글은 채팅에 나가지 않는다.

| 명령 | 하는 일 |
| --- | --- |
| `/경지 연기기 7` | 그 경지, 그 단계로 옮긴다 (단계를 빼면 첫 단계) |
| `/단계 23` | 단계 번호로 옮긴다 (1 범인 ~ 56 천인 천원) |
| `/영력` | 지금 단계 영력을 채운다 |
| `/과업` | 지금 단계 과업을 끝낸다 (고르기는 직접) |
| `/주머니 별씨 5` | 주머니에 넣는다 (영초, 천년영지, 홍령삼, 축기단, 별씨) |
| `/시간 밤` | 낮, 해질녘, 밤, 새벽으로 넘긴다 |
| `/초기화 확인` | 기록을 지우고 범인부터 |
| `/복구`, `/복구 확인` | 검수 명령을 처음 쓰기 전 기록을 보여 주고, 그 기록으로 되돌린다 |
| `/검수` | 명령 목록 |

기록을 바꾸는 명령을 처음 쓸 때 원래 기록을 DataStore 의 따로 된 키(`player_<UserId>_before_dev`)에 한 번 보관한다.
보관에 실패하면 명령을 멈춘다. 아래 경지로 옮기면 그 경지에 맞게 공법 장착과 경지 술법을 정리한다.

src/shared/               서버·클라 공용: 경지, 술법·공법, 수치 공식, 진행 로직, 조사

src/client/               UI
tests/run.luau            로직·맵 테스트 (Lune, 옥반 맵을 지어 자리·태그·땅 이름을 본다)

진행 시간 표를 출력한다 (과업에 드는 시간은 빠져 있다).

## UI 그림과 글꼴

Roblox 에는 한글 명조·붓글씨 글꼴이 없어서 HUD 글자도 그림으로 찍는다.

```sh
python3 tools/fetch_fonts.py      # 코드에 나오는 한글만 담아 송명·나눔명조 글꼴 받기 → art/fonts/
node tools/build_glyphs.mjs       # 글자판(아틀라스) 그리기 → art/out/glyphs_*.png
node tools/render_art.mjs         # art/assets.html 의 판·버튼·아이콘 그리기 → art/out/*.png
python3 tools/upload_art.py       # 바뀐 그림만 Roblox 이미지 에셋으로 올리고 src/client/Art.luau 갱신
```

`node` 스크립트는 Playwright 가 필요하다 (`NODE_PATH` 에 전역 playwright 경로, 필요하면 `CHROMIUM_PATH`).
HUD 나 서버 알림(src/server)에 새 한글 문구를 넣었으면 위 네 단계를 다시 돌린다.
글자판은 이어 쓴다: 이미 있는 글자는 같은 자리에 두고 새 글자만 새 페이지에 그려서, 다시 올라가는 그림은 새 페이지뿐이다
(처음부터 다시 채우려면 `node tools/build_glyphs.mjs --repack`). 새로 올린 그림은 Roblox 검수가 끝나야 게임에 보이므로
`tools/publish.py` 는 Art.luau 의 그림이 모두 검수를 통과할 때까지 기다렸다가 게시한다. 그래도 글자판을 못 받아 오면
그 글줄만 Roblox 글꼴로 찍는다(src/client/BitmapText.luau). `lune run tests/hud` 가 빠진 글자를 잡아 준다.
알림은 화면 위 가운데에 칠기 띠(src/client/Notice.luau)로 띄운다. 한꺼번에 몰리면 줄을 세워 차례로 띄우고,
경지 연출 중에는 멈췄다가 연출이 걷힌 뒤 띄운다. 글자판에 없는 글자(플레이어 이름 등)가 섞이면 그 알림만 Roblox 글꼴로 찍는다.

## 개발

필요한 도구: [Rojo](https://rojo.space) 7, [Lune](https://lune-org.github.io/docs) 0.10 (선택: StyLua, Selene)

```sh
rojo serve                      # Studio 의 Rojo 플러그인과 실시간 연동
lune run tests/run              # 로직·맵 테스트
lune run tests/hud              # 화면 UI 를 실제 인스턴스로 만들어 속성 검사
lune run tools/bake_place       # BlockSuseon.rbxl 다시 만들기
ROBLOX_API_KEY=... python3 tools/publish.py   # 플레이스 71891059039004 에 게시
```

게시 키에는 해당 체험의 `universe-places:write` 권한이 필요하다.
Studio 에서 저장(DataStore)을 시험하려면 게임 설정 → 보안 → "Studio 에서 API 서비스 접근 허용"을 켠다.
꺼져 있으면 기본값으로 진행하고 저장하지 않는다.
