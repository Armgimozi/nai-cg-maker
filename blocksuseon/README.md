# 블록수선전

웹소설 **회귀수선전**의 세계관(수선 경지 체계, 연국, 천겁, 영맥)을 바탕으로 한
로블록스 수선 시뮬레이터. 회귀·종명자 요소는 넣지 않았다.

## 플레이

| 조작 | 키 | 하는 일 |
| --- | --- | --- |
| 운기조식 | `R` | 제자리에 앉아 영기를 모은다. 움직이거나 뛰면 풀린다. |
| 돌파 | `B` | 경지의 마지막 단계에서 영력과 과업을 다 채우면 다음 경지로 넘어간다. |
| 상태창 | `C` | 경지·능력치와 익힌 술법·공법을 보고, 공법 장착·술법 단축칸·단축키를 정한다. |
| 술법 | `Q` `E` `Z` `X` (바꿀 수 있음) | 단축칸에 넣은 술법을 쓴다. 화면 아래 칸을 눌러도 된다. |
| 채집 | `F` (길게) | 영초를 먹거나 비급을 주워 익힌다. |

숫자 키 `1`~`9` 는 Roblox 기본 장비·도구 칸으로 남겨 둔다.
상태창의 "단축키" 줄에서 칸을 누르고 원하는 키를 누르면 바뀐다 (Q E T Y U G H J K L Z X V N P 중에서).
술법 줄의 작은 키 버튼으로 어느 칸에 넣을지 고른다. 새로 익힌 술법은 빈 칸에 저절로 들어간다.

- 영력은 연료이고, 다음 단계로 가는 열쇠는 그 단계의 **과업**이다. 과업은 화면 왼쪽 영력 막대 아래에 보인다.
  과업 줄을 누르면 할 일을 채팅으로 다시 알려 준다. 영력과 과업을 다 채우면 같은 경지 안에서는 저절로 오른다.
- 범인: 운기조식 30초로 영기를 느끼고, **영근**(천·진·잡영근)을 고르고, 영초를 하나 먹는다.
- 단수기: 내 영근 속성의 **오행처**를 돌며 운기하고(오행지의), 음양 박자(음양지의), 농도 막대(혼원지의) 내관을 한다.
- 내관(미니게임)은 과업 줄의 "내관" 버튼으로 연다. 천·진영근은 "건너뛰기"로 영력을 2.5배 내고 퍼즐을 넘길 수 있다(선통후각).
- 서버 공용 **낮밤**이 12분마다 돈다 (낮 7분, 밤 4분). 밤에만 하는 과업이 있다.
- 천겁은 원작대로 **원영기부터** 내린다. 원영기 1·2·3·4줄기, 천인기 5·10·15·20줄기.
  쓰러지거나 도중에 나가면 실패: 경지는 그대로, 영력 일부를 잃는다. 피해는 천겁을 맞는 본인에게만 들어간다.
- 연기기 14성은 성마다 할 일이 다르다.

  | 성 | 하는 일 |
  | --- | --- |
  | 1 칠십이지살 | 빛나는 맥의 순서를 기억해 짚는다 (9맥씩 8번) |
  | 2 삼십육천강 | 천괴~천교, 천강 별 이름 순서 기억 |
  | 3 십이지율 | 광장 네 귀퉁이 율점 등롱 12곳 곁에서 취령진을 펴고 운기 (취령진이 없으면 기초본을 준다) |
  | 4 십천간도 | 오행처 다섯 곳을 낮에 한 번(양간), 밤에 한 번(음간) |
  | 5 구궁귀일 | 구궁판 패를 맞바꿔 가로·세로·대각선 합 15 |
  | 6 팔괘완로 | 천겁대 기둥을 건 태 리 진 손 감 간 곤 순서로 F |
  | 7 칠성제의 | 칠수 고르기, 칠성단에 영초 7 바치기, 밤 시운에 제의를 올려 푸른 원으로 별빛 다섯 줄기 받기 |
  | 8 육합만로 | 사방 성대, 영산 꼭대기, 개울 바닥에서 운기 |
  | 9 오행진의 | 본명 속성을 골라 그 오행처에서 운기 |
  | 10 사상이의 | 낮에 20초, 밤에 20초 운기 |
  | 11 삼재규일 | 개울 바닥, 광장, 영산 꼭대기 순서로 운기 |
  | 12 이의합일 | 음양 박자를 끊기지 않고 24번 |
  | 13 일원일응 | 줄어드는 고리를 점에 세 번 잇달아 맞추기 |
  | 14 무극영운 | B 로 단전을 터뜨려 가닥(영근 속성 수의 제곱)을 시간 안에 모두 붙잡는다. 연단로에서 영초 6, 천년영지 1로 축기단을 빚어 두면 쉽다. 실패하면 영력 40%를 잃는다 |
- 축기기: 별 스물여덟 개(각수성~진수성)를 하나씩 맺는다. 밤마다 **영성우**가 내려 푸른 원 자리에 별씨가 박힌다(F 로 줍기).
  별마다 별씨 하나로 "응결" 내관(줄어드는 고리)을 한다. 수의 마지막 별은 그 방위 성대(1수 동, 2수 북, 3수 서, 4수 남)에서
  밤에 자리를 잡고 별자리를 긋는다. 제사한 칠수의 수에서는 별씨가 반만 들고 영력도 덜 든다. 3·4수는 영력이 더 든다.
  수를 하나 완성할 때마다 **정순지력**으로 최대 체력 +5%, 천겁 피해 -5%.
  진수성에서는 사방 성대를 도는 재제의와 천구도를 마친 뒤 B 로 **금단 응결**(천·지·인 농도 막대)을 한다.
- 결단기: 천시원(광장 운기, 기혈 정돈), 태미원(칠성단 낮과 밤 제의), 자미원(밤 영산 꼭대기, 별 잇기), 천상열차분야(밤 제의 별빛).
  결단기에 들면 경신술이 **비둔술**로 바뀌고, 자미원을 새기면 쓰러져도 10분에 한 번 그 자리에서 일어난다(**금단 재생**).
- 원영기 진입: B 를 누르면 **주마등**이 흐른다. 수행 일지의 기억을 최근 것부터 "연국에 처음 온 날"까지 거슬러 짚으면
  원영이 맺히고, 이어서 첫 **금색 천겁**(예고가 따라오다 멈추는 거대 금뢰 1줄기)이 내린다. 원영기에 들면 **허공이동**을 얻는다.
- 원영기: 여월지긍(밤 개울), 여일지승(새벽 동쪽 성대, 새벽은 30초뿐), 여오악지수(오악 중심 고르기, 오행처 다섯 곳.
  내 영근에 없는 속성은 오래 걸린다), 불건불붕(일월오악도, 도심 고르기). 단계마다 금색 천겁 2·3·4줄기.
- 천인기 진입: 천겁 다섯 줄기. 들면 **천기유도**(오악 중심 속성의 천지 현상)를 얻는다.
- 천인기: 고른 **도심**(채약, 진법, 연단, 천문, 좌관)에 몰입할 때만 **광기**가 찬다. 사계를 따라
  봄(목 오행처), 여름(화 오행처, 이립에서 **원영 출규**), 가을과 겨울(마을 노인 셋의 마지막 부탁, 종심), 천원(하루를 한 바퀴).
  지천명부터 천겁 예고를 조금 일찍 본다(예지). 단계마다 천겁 10·15·20줄기. 천원이 하계의 끝이다.
- **영맥** 위에서 운기조식하면 흡수가 빨라진다. 하품(마을, x1.5) · 중품(영초숲, 축기기 이상, x2.5) · 상품(영산 꼭대기, 결단기 이상, x4).
- 맵 곳곳(영산 층계 모서리, 숲, 강가, 천겁대, 가장자리)에 **비급**이 나타난다. 주우면 술법이나 공법을 익힌다.
  비급마다 이해할 수 있는 최소 경지가 있어서, 경지가 모자라면 그대로 남는다.

### 술법과 공법

| 종류 | 이름 | 효과 | 익힐 수 있는 경지 |
| --- | --- | --- | --- |
| 술법 | 경신술 | 보는 방향으로 몸을 날린다 (쿨타임 5초) | 범인 |
| 술법 | 영안 | 12초 동안 영초와 비급이 벽 너머로 보인다 (30초) | 단수기 |
| 술법 | 취령진 | 15초 동안 진 안에서 운기조식하면 흡수 두 배 (30초) | 연기기 |
| 술법 | 호신강기 | 3초 동안 천겁 낙뢰를 막는다 (25초) | 축기기 |
| 술법 | 허공이동 | 보는 방향으로 순간이동 (15초) | 원영기에 들면 얻는다 |
| 술법 | 원영 출규 | 원영이 가까운 영초를 대신 캔다 (40초) | 천인기 이립에서 얻는다 |
| 술법 | 천기유도 | 오악 중심 속성의 현상: 수 영초, 목 천년영지, 토 비급, 화 둘레 영력, 금 영물 끌어오기 (300초) | 천인기에 들면 얻는다 |
| 공법 | 토납법 | 운기조식 흡수 +30% | 범인 |
| 공법 | 백초경 | 영초에서 얻는 영력 +60% | 범인 |
| 공법 | 청심결 | 내관 판정 폭 +20%, 실패 손실 절반 | 단수기 |
| 공법 | 금강체 | 최대 체력 +40% | 연기기 |
| 공법 | 피뢰결 | 천겁 낙뢰 피해 -30% | 결단기 |
| 공법 | 천기감응 | 천겁 낙뢰와 제의 별빛 예고 +0.4초 | 결단기 |

공법 장착 칸은 처음 1칸, 연기기 2칸, 결단기 3칸. 수치와 목록은 [`src/shared/Skills.luau`](src/shared/Skills.luau) 에서 바꾼다.

### 경지 (수계, 범인~천인기)

| 경지 | 단계 | 다음 경지로 |
| --- | --- | --- |
| 범인 | 1 | B |
| 단수기 | 1 | B |
| 연기기 | 1성 칠십이지살 ~ 14성 무극영운 | 무극영운 내관 (변화 가닥 붙잡기, 축기단이 있으면 쉽다) |
| 축기기 | 각수성 ~ 진수성 (28별) | 금단 응결 내관 |
| 결단기 | 천시원, 태미원, 자미원, 천상열차분야 | 주마등, 금색 천겁 1줄기 |
| 원영기 | 여월지긍, 여일지승, 여오악지수, 불건불붕 (단계마다 천겁 2·3·4줄기) | 천겁 5줄기 |
| 천인기 | 지선과 이립, 불혹과 지천명, 천순과 종심, 천원 (단계마다 천겁 10·15·20줄기) | 하계의 끝 |

경지·단계 이름은 나무위키의 회귀수선전 설정 문서를 따랐다. 영근 고르기 절차, 시간 수치, 미니게임 형식은 게임 규칙이다.
경지는 [`src/shared/Realms.luau`](src/shared/Realms.luau), 단계별 과업은 [`src/shared/Tasks.luau`](src/shared/Tasks.luau),
영근은 [`src/shared/Roots.luau`](src/shared/Roots.luau) 에서 고친다.

### 맵: 연국(連國)

마을 광장(하품 영맥, 스폰) · 서쪽 개울 건너 영초숲(중품 영맥) · 북쪽 영산(층층이 감아 오르는 비탈, 꼭대기에 상품 영맥) · 북동쪽 천겁대.
맵은 플레이스 파일에 들어 있으니 Studio 에서 그대로 고쳐도 된다. 스크립트는 이름이 아니라 **태그**로 맵을 찾으므로
`Ground`, `Vein`(속성 `VeinId`, `Radius`), `HerbZone`, `ManualSpot`, `Site`(속성 `Site`, `Radius`) 태그만 유지하면 된다.
오행처 다섯 곳: 목은 영초숲 고목, 화는 마을 동쪽 대장간 화덕, 토는 영산 기슭 바위, 금은 천겁대 옆 쇠기둥, 수는 개울가.

## 파일

```
BlockSuseon.rbxl          완성된 플레이스 (Studio 로 열거나 그대로 게시)
default.project.json      Rojo 프로젝트
src/shared/               서버·클라 공용: 경지, 술법·공법, 수치 공식, 진행 로직, 조사
src/server/               서버: 운기조식, 천겁, 영초, 비급, 술법, 저장, 맵 생성
src/client/               UI
tests/run.luau            로직·맵 테스트 (Lune)
tests/hud.luau            화면 UI 생성 테스트 (Lune)
tools/bake_place.luau     Rojo 빌드 + 맵 굽기 → BlockSuseon.rbxl
tools/publish.py          Open Cloud 로 게시
```

밸런스는 [`src/shared/Balance.luau`](src/shared/Balance.luau)의 숫자만 바꾸면 된다. `lune run tests/run`이 영력만 따진
진행 시간 표를 출력한다 (과업에 드는 시간은 빠져 있다).

## UI 그림과 글꼴

Roblox 에는 한글 명조·붓글씨 글꼴이 없어서 HUD 글자도 그림으로 찍는다.

```sh
python3 tools/fetch_fonts.py      # 코드에 나오는 한글만 담아 송명·나눔명조 글꼴 받기 → art/fonts/
node tools/build_glyphs.mjs       # 글자판(아틀라스) 그리기 → art/out/glyphs_*.png
node tools/render_art.mjs         # art/assets.html 의 판·버튼·아이콘 그리기 → art/out/*.png
python3 tools/upload_art.py       # 바뀐 그림만 Roblox 이미지 에셋으로 올리고 src/client/Art.luau 갱신
```

`node` 스크립트는 Playwright 가 필요하다 (`NODE_PATH` 에 전역 playwright 경로, 필요하면 `CHROMIUM_PATH`).
HUD 에 새 한글 문구를 넣었으면 위 네 단계를 다시 돌린다. `lune run tests/hud` 가 빠진 글자를 잡아 준다.
알림은 화면에 따로 띄우지 않고 채팅창 시스템 메시지로 보낸다.

## 개발

필요한 도구: [Rojo](https://rojo.space) 7, [Lune](https://lune-org.github.io/docs) 0.10 (선택: StyLua, Selene)

```sh
rojo serve                      # Studio 의 Rojo 플러그인과 실시간 연동
lune run tests/run              # 로직·맵 테스트
lune run tests/hud              # 화면 UI 를 실제 인스턴스로 만들어 속성 검사
lune run tools/bake_place       # BlockSuseon.rbxl 다시 만들기
ROBLOX_API_KEY=... python3 tools/publish.py   # 플레이스 71891059039004 에 게시
```

게시 키에는 해당 체험의 `universe-places:write` 권한이 필요하다.
Studio 에서 저장(DataStore)을 시험하려면 게임 설정 → 보안 → "Studio 에서 API 서비스 접근 허용"을 켠다.
꺼져 있으면 기본값으로 진행하고 저장하지 않는다.
