# 미궁 라비린스 — 장비 늘리기 · 획득처 다시 짜기 (TASK C, 0.3.5 안)

주인 결정을 따른다. **무기 종류(대검·한손검·활·지팡이·홀·단검)를 게임에서 없앤다.** 무기마다 모양·공격 방식·요구 능력치·고유 효과가 따로 있다.
그 위에서 무기를 늘리고, 상자·시련·특별 시련에서도 좋은 무기가 나오게 한다. 대장간과 보스가 늘 정답이 아니게 한다.

- 데이터: `gear_spec.json` (새 무기 106개 items.yml 형식 · 기존 무기 바꿈 · 방어구 6세트 · loot 바꿈 · 특별 시련 · 새 실루엣 · 테스트)
- 계산 스크립트: `tools/gs_data.py`(설계 데이터) · `gs_core.py`(공식) · `gs_loot.py`(루팅·회차) · `gs_build.py`(검사·JSON) · `gs_md.py`(이 문서). `python3 tools/gs_md.py` 로 다시 만든다.
- 고유 효과 이름·수치는 효과 설계자의 `unique_spec.json` 카탈로그(26개)와 `directions.json` 방향(12개)을 그대로 쓴다. 기존 131개 무기의 효과는 그대로 둔다.

## 1. 무기 종류 없애기

### 1.1 없어지는 것 · 남는 것

| 없어짐 | 대신 |
|---|---|
| items.yml `weapon_type` | `attack: {style, speed}` — 공격 방식(근접·원거리·시전)과 기본 공격 속도. 플레이어에게 분류 이름으로 보이지 않는다 |
| 툴팁 분류 글자 "대검/한손검/활/지팡이/홀/단검" | 무기는 분류 줄 없이 "공격 속도 초당 1.5회 · 스킬 위력 31" 한 줄 |
| 도감·대장간의 종류 필터, "내 직업 추천 장비만 보기" | "지금 낄 수 있는 것만 보기"(요구 능력치 충족) |
| classes.yml `weapon_types`(추천 무기), 추천 무기 직업 스킬 재사용 −10% | 없음. 대신 직업 스킬 기본 재사용 대기를 0.9배로 (추천 무기를 들던 사람은 그대로) |
| 직업 스킬 피해의 무기 종류 환산 (`WeaponTypes.classSkillScale`) | 무기마다 **스킬 위력**(1.4) |
| 요구 능력치를 종류로 정함 (대검 STR …) | 무기마다 요구 능력치 (1.5). 값 공식 ceil(2.5×(L−1)) 은 그대로 |
| config `weapon_attack_speed` 종류별 표 | 무기마다 `attack.speed` (`none` 맨손 1.6 만 남김) |
| 시작 무기 = 추천 무기 중 최저 | classes.yml `starter_weapon: <id>` 로 직접 |
| 드롭 직업 편향 (`classes`) | 능력치 편향 (1.6) |

남는 것: 무기마다의 모양(실루엣)과 실제 공격 방식. 활 모양은 활(BOW 아이템, 당겨 쏘기)이고, 시전 무기는 기본 공격이 근접 휘두르기다(지금도 기본 투사체는 없다).

### 1.3 피해 공식 (종류 없이)

items.yml 131개에서 맞춘 공식 (`tools/gs_fit.py`, 피해 비율 평균 1.002 · 표준편차 0.015):

```
무기 힘      P(L)  = 7 + 0.25×(L−1) + 0.0195×(L−1)²
희귀도 배율  R     = 일반 1.00 · 고급 1.06 · 희귀 1.13 · 영웅 1.21 · 전설 1.31 · 신화 1.45
DPS 상수     K     = 근접 1.47 − 0.143×max(0, 공속 − 1.5) · 원거리 1.56 · 시전 1.22
피해 가운데값      = P(L) × R × K ÷ 공속           (정수 [lo, hi], 반폭 3~12% — 지금 평균 6.8%)
티어 위력  TP      = 피해 가운데값 × 공속 ÷ K       (= P(L) × R)
주 스탯 줄         = (1 + 0.22L) × 희귀도 계수(일반 0.6 · 고급 0.8 · 희귀 1.0 · 영웅 1.2 · 전설 1.45 · 신화 1.75), 굴림 ×0.85~1.15
부가 스탯          = 기준값(L) × 희귀도 계수 × 0.85~1.15 (능력치형 부가 ×0.6) — 개수: 일반·고급 1 · 희귀 2 · 영웅 3 · 전설 4 · 신화 5
                     기준값: hp 3+3.2L · mp 2+1.6L · defense 1+0.35L · crit_chance 0.01+0.0009L · crit_damage 0.03+0.003L ·
                     attack_speed 0.02+0.0009L · move_speed 0.01+0.0005L · cooldown_reduction 0.01+0.0009L · skill_damage 0.02+0.0015L ·
                     mana_regen 0.1+0.015L · hp_regen 0.2+0.05L · heal_power 1+0.8L · lifesteal·damage_reduction·evasion 0.01+0.0006L
요구 능력치        = ceil(2.5×(L−1)), 2 이하면 없음
```

K 로 옛 종류 배율을 다시 만든다 (그래서 기존 무기를 안 고쳐도 된다):

| 옛 종류 | 옛 피해 배율 | 공속 | K÷공속 | 차이 |
|---|---|---|---|---|
| sword_shield | 1.00 | 1.5 | 0.980 | -2.0% |
| greatsword | 1.55 | 0.95 | 1.547 | -0.2% |
| bow | 1.30 | 1.2 | 1.300 | +0.0% |
| staff | 1.10 | 1.1 | 1.109 | +0.8% |
| scepter | 0.95 | 1.3 | 0.938 | -1.2% |
| dagger | 0.62 | 2.2 | 0.623 | +0.4% |

빠른 근접 무기(공속 1.5 초과)는 K 가 조금 낮다. 적중 훅(고유 효과·흡혈)을 더 자주 켜서다.

### 1.4 직업 스킬 위력 — 무기마다 `skill_power`

지금은 직업 스킬 피해 = 공격력 × 스킬 배율 × (추천 무기 배율 ÷ 든 무기 배율)이다. 종류가 없어지면 이 환산을 못 한다.
그냥 공격력(무기 피해)을 쓰면 느리고 한 방이 큰 무기가 직업 스킬을 독차지한다(대검 1.55 vs 단검 0.62 = 2.5배).
초당 피해(피해 × 공속)를 쓰면 시전 무기가 손해다(시전 0.81 vs 원거리 1.04).

**제안: 스킬 위력 = 티어 위력 TP × skill_power_mult.**

```
skill_power      = 굴린 피해 가운데값 × 공속 ÷ K(방식, 공속) × skill_power_mult    (무기 없음 = 맨손 3)
skill_power_mult = 1.0 (기본) · 1.05 (시전 무기 — 기본 공격이 17% 약한 대신)
직업 스킬 피해   = skill_power × (1 + 0.02 × 직업 주스탯 혼합) × 스킬 배율 × classes.yml skill_scale
skill_scale      = 수호기사 1.00 · 광전사 1.55 · 사냥꾼 1.30 · 비전술사 1.05 · 사제 0.90 · 그림자 0.62
```

skill_scale 은 옛 "추천 무기 배율"을 직업 쪽으로 한 번 옮긴 것이다 (시전 직업은 ÷1.05). 그래서 0.3.4 에서 추천 무기를 든 사람은 직업 스킬이 그대로다(±2%).
이제 무엇을 들든 같은 단계면 직업 스킬 위력이 거의 같고, 차이는 무기의 고유 효과·부가 스탯에서 난다.

### 1.6 드롭 편향: 직업 → 능력치

loot.yml `own_class_bias: 0.65` 는 "내 직업에 어울리는 장비"(items.yml `classes`)만 고르던 편향이다. 종류가 없어지면 직업과 무기의 짝이 흐려진다.
바꿈: 무기 one_of 를 고를 때 65% 확률로 **요구 능력치가 내 능력치(직업 기본 + 분배) 상위 2개 안에 드는 무기**만 후보로 (없으면 전체). 방어구는 지금처럼 겉모습·classes.
이 명세의 모든 회차 계산은 이 규칙으로 했다. `classes` 필드는 새 무기에도 요구 능력치에서 뽑아 채워 둔다(옛 코드 호환).

### 2.3 왜 237개인가

- 한 캐릭터가 한 구간에서 고를 수 있어야 하는 것 = **내 주 능력치로 낄 수 있는 무기 3개 이상, 방향이 서로 다르고 획득처가 2곳 이상**.
  능력치 6개 × 3 = 18개가 바닥이다. 여기에 보스 고유 무기 2~3개, 두 능력치 무기(requires_any) 1~2개를 더하면 구간마다 22~23개.
- 10구간 × 23 = 230. 1~5 구간은 1층·2층 Lv5 무기가 겹쳐 25개, 46~50 구간은 신화 6개가 어려움 이상 전용이라 보통에서 고를 수 있게 22개를 맞췄다(전체 25).
- 그래서 131 + 106 = **237** (+106, 상한 +110 안). 새 무기를 구간마다 지금 모자란 만큼만 넣었다: 4·14·8·8·9·14·8·14·14·10.
- 더 늘리지 않는 이유: 같은 구간 같은 방향·같은 능력치가 겹치기 시작하면 "선택지"가 아니라 "중복"이 된다. 지금 수에서 겹치는 쌍은 0개다.

## 4. 구간마다 "정답이 하나가 아니다" — 증명 표

열: 희귀도·숨은 Lv · 방식 · 공속 · 피해 · DPS(피해 가운데값 × 공속) · 티어 위력 TP(대장간 기준 대비) · 주 부가 스탯 · 방향 · 요구 · 획득처 · 고유 강도 s · 자기 상황.
"자기 상황" = 효과 설계자 규칙 P′×(1+2B) ≥ 구간 최고 P′×(1+B최고) — 효과가 맞는 상황(무리·빈사·출혈 빌드 등)에서 효과 가치가 두 배라고 볼 때 구간 최고 무기를 이기면 ✔.
P′ = TP × (1 + 부가 스탯 가치 + 0.1 × 무기 스킬 수). 굵게 = 새 무기.

## 5. 특별 시련 (가장 적은 공사로)

### 5.1 무엇인가

- 층마다 있는 시련방(기믹방) 하나가 **30% 확률로 "특별 시련"**이 된다. 기믹은 같고 **조건 하나**가 붙는다. 들어가면 바로 알려 준다.
- 기믹 성공 + 조건 지킴 → 평소 상자(gimmick_floor_N) **에 더해** 특별 상자(`special_trial_fNN`, 개인 루팅)가 하나 더 놓인다. 경험치 +50%.
- 기믹 성공 + 조건 깨짐 → 평소 상자만 (실패가 아니다). 기믹 실패 → 지금과 같다.
- 같은 층을 4번 연속 특별 시련 없이 돌면 다음 방문은 반드시 특별 시련 (`pity_visits: 4`, 파티원 중 가장 큰 값 — 선택 기능, PlayerData 층별 카운터).
- 특별 상자는 그 층 특별 시련 전용 무기 1개 확정 (+ 6·9층은 특별 시련 방어구 50%) + 그 층 정수 1.

### 5.2 조건 4종 (공통 구현)

| id | 이름 | 판정 | 그 기믹이 지원해야 하는 것 |
|---|---|---|---|
| `swift` | 서두름 | 기믹 시작부터 성공까지 `seconds` 초 이하. 보스바에 남은 초 | 없음 (GimmickRoom.elapsed) |
| `unscathed` | 무상 | 방 안에서 최대 HP 3% 이상 맞은 횟수 ≤ 2 + 파티원 1명당 1 | 없음 (피해 훅) |
| `abstain` | 절제 | 방 안에서 물약·주문서를 하나도 안 씀 | 없음 (소모품 훅) |
| `flawless` | 무결 | 기믹의 "실수"(기회 하나 잃음) 0번 | 실수할 때 `noteMistake()` 를 부른다 — lever_sequence · resonance_tune · book_cipher · gear_timing 만 |

### 5.4 문구 (공략 없이, 분위기만)

| 자리 | 문구 |
|---|---|
| 방 안 글자판 | `<gold><b>✦ 특별 시련: {기믹 이름} ✦</b></gold>` + 기믹 안내 + `<yellow>{조건}</yellow>` |
| 들어갈 때 가운데 글자 | <gold><b>특별 시련</b></gold> / <gray>{condition_short} |
| 채팅 | <gold>✦ 특별 시련</gold> <gray>— 오늘의 방은 무언가 다르다. <yellow>{condition}</yellow> |
| 조건 `swift` | 모래시계가 뒤집혔다. {seconds}초 안에 끝내라. |
| 조건 `unscathed` | 이 방은 상처를 세고 있다. {hits}번 넘게 다치지 마라. |
| 조건 `abstain` | 물약 냄새를 싫어하는 방이다. 아무것도 마시지 마라. |
| 조건 `flawless` | 한 번의 실수도 기억된다. 틀리지 마라. |
| 조건 깨짐 | <gray>특별 조건이 깨졌다 — 이번 상자는 평소와 같다. |
| 조건 지킴 (성공 때) | <gold><b>특별 시련 성공!</b></gold> <gray>상자 하나가 더 놓였다. |

기믹을 푸는 방법은 적지 않는다. 조건은 "무엇을 하지 마라 / 언제까지"만 말한다.

### 5.5 설정 키

```yaml
# dungeon.yml
special_trial:
  enabled: true
  chance: 0.3          # 층 방문마다 시련방이 특별 시련일 확률 (시드 고정)
  pity_visits: 4         # 이만큼 연속 못 보면 다음은 확정 (0 = 끔)
  xp_bonus: 0.5          # 조건까지 지키면 시련 경험치 ×1.5
  conditions:
    swift:     {time_factor: 0.7, min_seconds: 40, default_seconds: 75}
    unscathed: {hits: 2, per_member: 1, min_damage: 0.03}
    abstain:   {potions: true, scrolls: true}
    flawless:  {}
# floors.yml (층마다, 생략하면 위 기본표)
#  special_trial: {conditions: [flawless, swift], seconds: 60}
# loot.yml
#  special_trial_f01 … special_trial_f10   (6.3)
```

## 8. 모델

### 8.1 규칙

- 새 무기 106개 중 74개가 새 실루엣 15종, 32개가 기존 템플릿(longsword·kris·dagger·katar·great_axe·cleaver·glaive·greatsword·falchion·broadsword·mace·sickle·fang_blade·longbow·recurve_bow·composite_bow·blade_bow·staff_orb·staff_ring·sun_scepter·chalice_scepter·censer_staff·bell_scepter)을 새 색으로.
- 테마 장식(dress_blade·dress_shaft·dress_bow·층 테마 THEME_KEYS)은 id 로 잡힌다. 새 id 는 모두 기존 키(moss/corridor/root · skitter/silk · miners/ore_ · spore/mycel/glowcap/hypha · brine/tide/eel/drowned/sluice/verdigris · ember/cinder/slag/anvil/bellows/forge · rime/frost · prism/geode/amethyst/shardglass/crystal/resonan · ink/lore/index · clock · abyss/void)를 품는다. `pit_*` 두 개는 style rusted_iron → forge.
- 희귀도 장식 단계(P.lv 0~5)는 그대로: 일반 깨끗 → 희귀 테두리·보석 → 영웅 테마 모티프. 새 무기에 전설·신화는 없다(아우라·애니메이션 없음).
- **손에 드는 각도**: 0.3.4 의 모양별 방식 그대로 — `voxel/weapons.HOLD[shape]`(fp_yaw), `TWO_HANDED`, 활은 `BOWS`(displays.voxel_bow), `tools/hold_preview.HEAD_SHAPES`(옆으로 머리가 있는 모양, 바닐라 도끼 행과 비교). 새 모양마다 아래 표의 값을 넣고 `python tools/hold_preview.py --shapes <새 모양들>` 로 시트를 보고 metrics 를 같은 무게 기존 모양과 비교한다.

## 12. 주의 · 남은 일

- 대장간이 싸다. 재료가 1회에 넉넉해 대장간 무기는 1회 안팎이면 나온다. 이 명세는 대장간을 "확정 바닥값"으로 두고 다른 곳을 효과로 차별했다. 대장간을 더 어렵게 하려면 레시피의 정예 재료를 2~3개로 올리는 것이 가장 덜 건드리는 방법이다(1회 3.6~5.5개 → 1회 안팎 그대로라 효과는 작다). 강화 골드가 더 큰 골드 소비처다.
- 보스 고유 무기 회차(1~9회)는 그대로 뒀다. 능력치 편향으로 바꾸면 "내 직업 무기" 대신 "내 능력치 무기" 확률이라 bossUniqueWeaponsDropOftenEnough 테스트의 숫자를 다시 맞춰야 한다 (보스 묶음 대부분이 능력치가 서로 달라 크게 변하지 않는다).
- 효과 설계자의 기존 131개 강도(s)는 종류별 구간으로 계산된 값이다. 종류가 없어지면 구간 전체로 다시 계산하는 편이 맞다 — 이 명세는 새 무기만 구간 전체 규칙으로 계산했다. 다시 계산하면 대장간·몬스터·상자 무기 일부의 s 가 올라간다(구간 최고가 보스 전설이라).
- 새 영웅 무기 63개의 무기 스킬은 방향별 조합형 틀 12종을 층 연출(proj_*·*_burst·*_slash)로 바꿔 쓴 것이다. 이름은 모두 다르다. 보스·대장간 상위 무기처럼 무기마다 완전히 다른 조합을 원하면 따로 다듬는다.
- 특별 시련 성공률 0.65 는 추정이다. 테스트 서버에서 층마다 10번씩 재 보고 chance·조건 수치를 맞춘다.
- 겉모습별 방어구 장단점(판금·가죽·천)은 다른 설계 작업이다. 새 6세트는 look 만 맞춰 두었다.
