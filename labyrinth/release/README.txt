모드 없이 플러그인 하나 + 리소스팩 하나로 돌아갑니다. 무기·방어구·몬스터·보스·NPC·UI 는
전부 이 서버팩을 위해 새로 그리고 만든 것입니다. 친구는 바닐라 마인크래프트 26.3 으로 들어오면 됩니다.


■ 켜는 법 (윈도우)

  1. 이 폴더를 원하는 곳에 압축 해제합니다. (바탕화면 등)
  2. 풀린 폴더 안의 start.bat 을 더블클릭합니다.
     - zip 을 연 상태에서 바로 실행하면 안 됩니다. 꼭 압축을 먼저 풀어 주세요.
     - 처음 한 번은 Java 25 와 Paper 26.3(최신 안정판) 서버 파일을 자동으로 내려받습니다. (1~2분)
       받은 파일은 검사값(sha256)으로 깨지지 않았는지 확인합니다.
     - "동의하면 Y 를 입력하고 Enter" 가 나오면 마인크래프트 EULA(https://aka.ms/MinecraftEULA)를
       읽어 보고 Y 를 입력하고 Enter.
     - Windows 방화벽 창이 뜨면 "허용" 을 누르세요. (친구가 들어오고 리소스팩을 받으려면 필요)
  3. 창에 "Done" 이 뜨면 서버가 켜진 것입니다.
  4. 마인크래프트 런처에서 버전을 26.3 으로 고르고 실행
     → 멀티플레이 → 서버 추가 → 주소에 localhost
  5. 처음 접속하면 "서버 리소스팩" 을 받을지 묻습니다. 꼭 "예" 를 누르세요.
     (무기·몬스터·메뉴 화면이 전부 이 팩으로 그려집니다. 거절하면 종이 아이콘과 투명한 몬스터만 보입니다.)
  6. 관리자 명령어를 쓰려면 서버 창에 op 내닉네임 을 입력합니다.
  7. 끌 때는 서버 창에 stop 을 입력합니다. (창을 그냥 닫으면 저장이 안 될 수 있음)

  맥/리눅스는 Java 25 (https://adoptium.net → Temurin 25) 를 설치한 뒤 터미널에서
  sh start.sh 를 실행하세요. 메모리는 MEMORY=6G sh start.sh 처럼 바꿀 수 있습니다.


■ 처음 한 번: 관리자 초기 설정  (꼭 해 주세요)

  1. 처음 접속한 사람에게 "서버 초기 설정" 창이 자동으로 뜹니다. (op 가 아니어도 됩니다)
     - 난이도 4가지 중 하나를 고릅니다:  쉬움 · 보통 · 어려움 · 악몽
       (몬스터 HP·피해·드롭·경험치·경고 시간이 달라집니다. 처음이면 "보통" 을 권해요.)
     - 입구는 마을의 "미궁의 아가리" 로 정해져 있어 따로 고르지 않습니다. (아래 '등불 어귀 마을')
     - "확정" 을 누르면 미궁이 열립니다. 정하기 전에는 아무도 미궁에 들어갈 수 없습니다.
     창을 닫았으면 /미궁 난이도 로 다시 열 수 있고, 서버 창(콘솔)에서는
     labadmin setup normal 처럼 바로 정할 수 있습니다.
  2. 난이도는 서버 전체에 하나입니다. 들어갈 때 고르지 않습니다. 나중에 바꾸려면 누구나
     /미궁 난이도  (또는 /미궁 난이도 <easy|normal|hard|nightmare>)
     관리자만 바꾸게 하려면 plugins/Labyrinth/config.yml 의 setup: everyone_can_set_difficulty: false  (진행 중인 공략은 다음 입장부터 적용)

  3. 입구·마을 NPC 는 세우지 않아도 됩니다. 이 서버팩의 world 폴더에 마을이 미리 지어져 있고,
     서버를 처음 켤 때 입구(게이트)와 NPC 5명이 마을 자리에 자동으로 놓입니다.
     (world 폴더를 다른 월드로 바꿔 쓸 때만 예전처럼 /labadmin setentrance block|npc, /labadmin setnpc <id> 를 씁니다.
      setentrance 는 원래 블록을 기억했다가 /labadmin removeentrance 로 그대로 되돌립니다.)


■ 등불 어귀 마을  (미궁 입구 마을)

  서버를 켜고 들어오면 마을 한가운데 "등불 광장" 분수 앞에서 시작합니다.
  광장에서 계단을 올라간 곳의 커다란 보라색 룬 아치가 미궁 입구 "미궁의 아가리" 입니다.
    · 아치 아래 계단을 내려가 검은 문을 우클릭하거나, 앞마당의 안내인 벨라에게 말을 걸면 입장 메뉴.
      파티원은 모두 검은 문 가까이(8칸 안)에 모여 있어야 함께 들어갑니다.
    · 미궁에서 나오면(/미궁 귀환, 공략 성공·실패) 이 게이트 앞으로 돌아옵니다.
  광장 둘레의 건물 — 건물 안 NPC 를 우클릭하거나 표시된 블록(모루·교탁·독서대·계산대)을 우클릭하면 메뉴가 열립니다.
    · 전직의 전당 (파란 지붕·종탑)     전직관 세라핀 — 직업 선택
    · 기록 보관소 (보라 유리 돔)       기록관 노아 — 칭호
    · 두르간의 대장간 (큰 굴뚝)        대장장이 두르간 — 제작
    · 핀의 떠돌이 상점 (줄무늬 천막)   떠돌이 상인 핀 — 물약·소모품
    · 검은 등불 여관 · 마을집 세 채 · 우물 · 길잡이 표지판 · 광장 게시판
  마을은 보호 구역입니다: 블록을 부수거나 놓을 수 없고(관리자도 크리에이티브일 때만), 밤에도 마을 안에는
  적대 몹이 자연 스폰하지 않습니다. 마을 밖은 평범한 마인크래프트 월드라 마음껏 탐험·건축하면 됩니다.
  어디서든 /미궁 마을 (또는 메인 메뉴의 '마을' 버튼) = 광장으로 돌아오기. (미궁 안에서는 먼저 /미궁 귀환)

■ 친구 들어오게 하기

  [같은 집, 같은 와이파이]
    친구는 서버 주소에 내 PC 의 내부 IP 를 넣습니다.
    내부 IP 확인: 시작 → cmd → ipconfig → "IPv4 주소" (예: 192.168.0.12)

  [다른 집에서]
    방법 A. 공유기 포트포워딩
      공유기 설정에서 25565(게임), 8163(리소스팩) 두 TCP 포트를 내 PC 로 열어 줍니다.
      친구는 내 공인 IP 로 접속합니다. (네이버에 "내 아이피" 검색)
    방법 B. playit.gg 같은 터널 프로그램  (리소스팩용 터널을 하나 더 만드세요)
      playit 은 기본으로 게임 포트(25565)만 연결해서 친구가 리소스팩을 못 받습니다.
      1) playit 에서 터널을 하나 더 추가합니다: 종류 TCP, 로컬 포트 8163
      2) 만들어진 주소가 예) abc-def.gl.at.ply.gg:12345 라면 plugins/Labyrinth/config.yml 의
           pack:
             public_host: "abc-def.gl.at.ply.gg"
             public_port: 12345
         처럼 적고 서버를 다시 켭니다 (/labadmin reload 도 됨).
      3) 같은 PC·같은 와이파이로 들어오는 사람은 자동으로 내 PC 주소에서 받으니 그대로 둬도 됩니다.
    방법 C. 리소스팩을 인터넷에 올리기 (터널을 하나 더 만들기 싫을 때)
      plugins/Labyrinth/pack/labyrinth-pack.zip 을 mc-packs.net 같은 리소스팩 무료 호스팅에 올리고,
      알려 주는 다운로드 주소와 SHA-1 을 config.yml 에
        pack:
          url: "https://…/labyrinth-pack.zip"
          sha1: "SHA-1 값"
      로 적은 뒤 서버를 다시 켭니다. 업데이트할 때마다 새 팩을 다시 올려야 합니다.

  ※ server.properties 의 online-mode=true 라서 정품 계정만 들어올 수 있습니다.
  ※ PvP 는 켜져 있습니다. 같은 파티원끼리만 서로 못 때립니다 (아래 [PvP] 참고).
     PvP 를 아예 끄려면 plugins/Labyrinth/config.yml 의 pvp: enabled: false 로 바꾸고 /labadmin reload.


■ 게임 방법

  [시작]
    /미궁 (또는 /lab) → 메인 메뉴. 입장·파티·스탯·직업·칭호·장신구·대장간·상점·도감이 다 여기 있습니다.
    먼저 직업을 고르세요: /직업  (전직관 NPC 를 우클릭해도 됩니다)

  [직업]  6가지 — 괄호 안은 추천 무기. 무기·방어구·장신구는 어느 직업이든 다 쓸 수 있습니다
    수호기사(탱커, 검과 방패) · 광전사(근접, 대검) · 사냥꾼(원거리, 활)
    비전술사(광역 마법, 지팡이) · 사제(치유·버프, 홀) · 그림자(암살·치명타, 단검)
    추천 무기를 들면 직업 스킬 재사용 대기 −10%. 처음 전직하면 추천 무기를 하나 받습니다.
    같은 등급 무기라면 종류가 달라도 직업 스킬 위력은 같습니다 (기본 공격·무기 스킬은 든 무기 그대로).

  [직업 스킬]  무엇을 들었든 (직업만 있으면)
    F               = 스킬 1  (Lv.1)
    웅크리기 + F    = 스킬 2  (Lv.8)
    Q               = 스킬 3  (Lv.18)
    웅크리기 + Q    = 궁극기  (Lv.30)
    직업이 있으면 무엇을 들었든 F(손 바꾸기)와 Q(버리기)는 스킬로 바뀝니다. (맨손일 때 Q 스킬은 안 나갑니다)
    추천 무기(직업마다 다름)를 들면 직업 스킬 재사용 대기가 짧아집니다. 바닐라 칼·도끼·활도 원래 공격력대로 들어갑니다.
    아이템을 버리거나 손을 바꾸려면 인벤토리 창을 열고 Q·F 를 누르거나 끌어서 밖에 놓으세요.
    웅크리기 = 키 설정의 "웅크리기" 키 (기본 Shift, Ctrl 로 바꿔 둔 사람은 Ctrl). F·Q 도 바꿔 둔 키를 따릅니다.
    게임 안의 키 안내(액션바·툴팁·직업 메뉴)는 각자 설정한 키 이름으로 보입니다.
    마나(MP)는 액션바 오른쪽 파란 막대입니다. 시간이 지나면 찹니다.

  [무기 스킬]  일부 상위 무기에만 붙어 있고, 무기마다 다릅니다
    우클릭 = 무기 스킬,  웅크리기 + 좌클릭 = 두 번째,  웅크리기 + 우클릭 = 오의
    소수의 무기는 좌클릭(휘두르기)만으로 검기 같은 기본기가 나갑니다.
    무기 설명(툴팁)에 [우클릭] 처럼 쓰는 법과 재사용 대기 시간이 적혀 있어요. 활은 그냥 당기면 쏩니다.
    전설·신화 무기는 텍스처가 GIF 처럼 움직이고, 들고 있으면 몸 주위에 아우라가 돕니다.

  [레벨과 스탯]
    몬스터·보스를 잡으면 경험치. 최고 Lv.50. 처음(Lv.1)부터 스탯 포인트 5, 레벨이 오를 때마다 5 씩 더.
    /스탯 에서 힘(STR)·민첩(DEX)·지능(INT)·체력(VIT)·정신(WIS)·행운(LUK)에 나눠 줍니다.
    잘못 찍었으면 '스탯 초기화 두루마리' (상점) 로 되돌립니다.
    화면 아래(핫바 위)에 HP·MP 막대, 레벨, 경험치 줄, 골드, 걸린 상태이상이 그려집니다.

  [파티]  /파티  (메뉴) 또는 명령어
    /파티 생성 · 초대 <닉네임> · 수락 · 거절 · 탈퇴 · 추방 <닉네임> · 위임 <닉네임> · 해산 · 채팅 · 정보
    파티장이 입장하면 입구 근처(8칸)에 있는 파티원 전원이 함께 들어갑니다.
    혼자 들어가도 됩니다. 인원이 많을수록 미궁도 사나워집니다:
      몬스터 HP ×(1 + 0.6×(인원−1)), 피해 ×(1 + 0.08×(인원−1)), 보상은 조금 늘어남 (config.yml 에서 조정)
    아이템 드롭은 사람마다 따로 굴리고, 자기에게만 보입니다. 서로 뺏을 일이 없어요.

  [PvP]  따로 신청하는 대전은 없습니다. 규칙은 하나:
    같은 파티원끼리는 야생·마을·미궁 어디서든 서로 다치지 않습니다. (칼·활·스킬·물약·불·TNT·늑대 전부)
    그 밖의 사람(다른 파티·솔로)은 어디서든 공격할 수 있습니다. 친구와 같이 다니려면 먼저 /파티 를 맺으세요.
    마을 안(마을이 있는 월드)은 PvP 금지입니다.
    플레이어끼리는 피해가 ×0.7 이고, 한 번에 최대 HP 의 35% 까지만 들어갑니다 (한두 방에 죽지 않게).
    내 파티원 이름은 초록색으로 보입니다. 다른 파티와 싸움이 시작되면 화면 아래에 'PvP' 가 잠깐 뜹니다.
    야생에서 죽으면 바닐라처럼 소지품을 떨어뜨립니다 (keepInventory 게임 규칙). 미궁 안에서는 잃지 않습니다.
    파티를 나가면 그때부터 남입니다 — 미궁 안에 같이 남아 있어도 서로 맞습니다.
    서버장: /labadmin pvp 로 지금 규칙·배율·마을 안전지대를 확인. 숫자는 config.yml 의 pvp: 에서 바꿉니다.

  [미궁]  지하 1층 ~ 10층
    1 이끼 낀 회랑 · 2 거미줄 갱도 · 3 균사 동굴 · 4 잠긴 수로 · 5 용광로 심장부
    6 서리 묘역 · 7 수정 공명동 · 8 망각의 서고 · 9 태엽 성소 · 10 심연의 핵
    들어갈 때마다 미로가 새로 만들어집니다. 갈림길·막다른 길·돌아가는 길이 섞인 진짜 미로라
    보스방까지 가는 길을 직접 찾아야 합니다. 전투방·정예방·보물방·기믹방(퍼즐)·휴식방을 지나
    보스방의 층 주인을 쓰러뜨리면 아래층 계단이 열립니다.
    /미궁 지도 (또는 메인 메뉴의 탐험 지도) = 파티가 지나온 길을 채팅에 그려 줍니다.
    복도 곳곳에 함정이 숨어 있습니다. 바닥이 살짝 다른 칸을 조심하세요. 웅크린 채 다가가면 해체할 수 있습니다.
    막다른 길에는 보물 상자(나무·철·금)가 있습니다. 상자 안 몫은 사람마다 따로입니다.
    가끔 상자인 척하는 미믹이 있고, 금 간 벽 너머에는 비밀방이, 어딘가에는 열쇠로 여는 금고가 있습니다.
    처음엔 1층만 열려 있고, 층을 깨면 다음 층이 열립니다. 파티는 파티원 중 가장 낮은 해금층까지.
    층마다 보스가 저마다 다른 기믹과 패턴(경고 장판, 페이즈 전환, 광폭화)을 씁니다.
      그로브(1층) · 베셀라(2층) · 무르노크(3층) · 오스릭(4층) · 카르둠(5층)
      시린(6층) · 다이아드(7층) · 오르벨(8층) · 테오라(9층) · 넬카르(10층)
    깊은 층에는 드래곤·용인·나가·켄타우로스·하피·리치·미노타우로스·거대 벌레도 나옵니다.
    보스와 기믹방의 공략법은 글로 알려 주지 않습니다. 경고 장판·표식·소리를 보고 직접 알아내세요.
    같은 보스·기믹방에서 여러 번 실패하면 다음 도전 때 보스바 아래·휴식방 NPC·시련 안내에
    단서가 한 단계씩 또렷해집니다 (파티원 중 가장 많이 실패한 사람 기준. config.yml 의 hints 에서
    mode: progressive | none | full, thresholds: [2, 4, 6] 으로 조정).
    /미궁 귀환 = 미궁에서 나와 입구로.  /미궁 정보 = 지금 층 정보.

  [죽으면]
    미궁에 들어가면 누구나 서바이벌 모드가 됩니다 (크리에이티브로 들어와도 — 나가면 원래 모드로).
    미궁 안에서는 아이템을 잃지 않습니다. 쓰러지면 관전 모드가 되고,
    파티원이 휴식방에 닿거나 보스를 쓰러뜨리면 부활합니다. 사제의 '부활의 성가' 로도 일으킬 수 있어요.
    파티 전원이 쓰러지면 공략 실패 → 입구로 돌아옵니다.

  [장비 얻는 법]
    · 일반 몬스터 드롭 (재료 + 가끔 장비)
    · 정예 몬스터·보스 드롭 (보스 전용 장비)
    · 보물방 상자와 기믹방 보상
    · 대장장이 제작 — 몬스터 재료 + 골드 (/미궁 대장간 또는 대장장이 NPC)
    · 상점(물약·두루마리) · 칭호 보상
    무엇을 어디서 얻는지는 /도감 에 다 나옵니다.
    희귀도: 일반 < 고급 < 희귀 < 영웅 < 전설(금빛, 아우라) < 신화(붉은빛, 움직이는 아우라)
    같은 세트 방어구를 2개·4개 입으면 세트 효과. 장신구는 /미궁 장신구 의 2칸에 낍니다.

  [강화]  대장간 메뉴의 [강화] 버튼 또는 /미궁 강화
    미궁 무기·방어구·방패를 +1 ~ +10 까지 올립니다 (장신구·바닐라 장비는 불가).
    단계마다 무기는 피해, 방어구·방패는 방어·HP 가 기본값의 6% 씩 오릅니다 (+10 = ×1.6). 다른 부가 스탯은 그대로.
    재료 = 강화석 + 골드. 강화석: 하급(1~3층) · 상급(4~7층) · 최상급(8~10층) 몬스터·보스·상자에서.
      하급 강화석은 떠돌이 상인 핀도 팝니다.
    +4 까지는 반드시 성공, 그 뒤로는 확률이 점점 떨어집니다 (+10 은 20%).
    +7 이상에서 실패하면 한 단계 내려갑니다. '강화 보호 주문서' 를 넣으면 실패해도 그대로 (정예·보스가 드물게 줌).
    +8 이상 성공은 서버 전체에 방송됩니다. +7 부터 이름이 금빛이 되고 광택이 돌며, +10 장비는 은은한 빛 입자를 냅니다.

  [칭호]  /칭호
    업적을 이루면 칭호를 얻고, 하나를 골라 달면 채팅·탭 목록·이름표 앞에 붙습니다. 일부는 작은 스탯 보너스.
    "서버 최초" 칭호는 그 층을 서버에서 처음 돌파한 파티 전원만 받고, 서버 전체에 방송됩니다.
    솔로 클리어 · 무사망 클리어 · 난이도별 클리어 · 스피드런 · 처치 수 · 레벨 · 전설/신화 획득 · 제작 …
    /미궁 기록 = 각 층 서버 최초 돌파 파티와 최단 기록.

  [도감]  /도감 (또는 /codex)
    모든 무기·방어구·장신구·재료·소모품을 종류·희귀도별로, 몬스터·보스를 층별로 보여 줍니다.
    아이템마다 드롭하는 몬스터·보스, 보물 상자, 제작 재료, 상점 가격이 적혀 있어요.

  [명령어]
    /미궁 (/lab)      메인 메뉴 · 입장 · 귀환 · 정보 · 지도 · 메뉴 · 장신구 · 대장간 · 강화 · 상점 · 기록 · 도감
    /파티 (/party)    파티 메뉴와 명령
    /스탯 (/stats)    스탯 분배
    /직업 (/class)    직업 선택·정보·스킬
    /칭호 (/title)    칭호 장착·목록·기록
    /도감 (/codex)    아이템·몬스터 도감

  [관리자 명령어]  /labadmin (= /미궁관리), op 또는 labyrinth.admin 권한
    setup|difficulty <난이도>       초기 설정 / 난이도 변경
    setentrance [block|npc]        입구 세우기 · removeentrance 입구 치우기(원래 블록 복원)
    setnpc <id> · removenpc <id> · npcs
    give <아이템> [개수] [플레이어]   아이템 지급 (탭 키로 아이템 id 자동 완성)
    level|xp|gold|points <플레이어> <값>   레벨·경험치·골드·스탯 포인트
    unlock <플레이어> <층>           층 해금
    tpfloor <층>                    그 층으로 바로 (관리자 테스트 입장 — 게임 모드를 바꾸지 않음)
    spawnmob <id> · spawnboss <층> [인원] · endboss · bosses · killmobs [반경]
    instances · endinstance <id>    진행 중인 공략 목록·강제 종료
    title grant|revoke <플레이어> <id> · title recheck
    loot <테이블> [플레이어] · blacksmith [플레이어] · weaponskills · enhance <단계> [플레이어]
    info [플레이어] · pack (리소스팩 상태·다시 보내기) · reload (설정·콘텐츠 다시 읽기)
    selftest [층 수]                자가 진단: 플레이어 없이 층 생성·몬스터/보스 소환·피해·정리를 돌려 보고
                                    문제가 있으면 하위 시스템별로 알려 줍니다 (서버 창에서도 됨)


■ 설정 바꾸기

  plugins/Labyrinth/ 폴더 (서버를 한 번 켜면 생깁니다)
    config.yml      난이도 프리셋(difficulties), 파티 인원 배율(party), 리소스팩(pack: port·url·sha1),
                    전투(피해 숫자·치명타), 레벨 곡선(level), 무기 공격 속도, 몬스터(mobs: 정예 변종 확률),
                    점진 힌트(hints: mode·thresholds)
    dungeon.yml     미궁 생성 속도, 동시 공략 수, 문 닫힘, 휴식방 회복, 대체 보스 배율 …
    content/*.yml   아이템·몬스터·보스·층·루팅·제작법·칭호·NPC·직업 수치 (밸런스는 여기서)
  고친 뒤 게임 안에서 /labadmin reload  (진행 중인 공략은 다음 입장부터)
  손대지 않은 content 파일은 플러그인을 새 판으로 바꾸면 자동으로 새 내용으로 바뀝니다.
  플레이어 진행: plugins/Labyrinth/players/<uuid>.yml · 서버 최초 기록: plugins/Labyrinth/records.yml


■ 리소스팩

  플러그인이 8163 포트로 리소스팩을 직접 보내 줍니다 (Labyrinth.jar 안에 들어 있음).
  같은 파일이 이 폴더에 Labyrinth-pack.zip (검사값 Labyrinth-pack.sha1) 으로도 들어 있습니다.
  터널 등으로 8163 포트를 못 열 때는 이 zip 을 인터넷에 올리고 config.yml 의 pack: url: / sha1: 에
  주소와 검사값을 적으세요.


■ 문제가 생기면

  · 창이 바로 닫히거나 서버가 안 켜짐 → 이 폴더의 start-log.txt 를 메모장으로 열어
    마지막 줄을 확인하세요. 어디서 멈췄는지 적혀 있습니다.
  · localhost 로 접속이 안 됨 → 서버 창에 "Done" 이 떴는지, 마인크래프트 버전이 26.3 인지 확인.
    정품 계정이 아닌 런처를 쓰면 server.properties 의 online-mode=true 를 false 로 바꾸고
    서버를 다시 켜야 들어올 수 있습니다. (이때는 아무나 남의 닉네임으로 들어올 수 있으니
    주소는 친구에게만 알려 주세요.)
  · "미궁에 들어갈 수 없음 / 난이도를 정하지 않음" → 관리자가 초기 설정을 하지 않았습니다.
    op 를 가진 사람이 접속하거나 서버 창에 labadmin setup normal.
  · 무기가 종이로, 몬스터가 안 보임 → 리소스팩을 안 받았습니다. 멀티플레이 → 서버 편집 →
    서버 리소스팩: 사용. 친구만 안 되면 8163 포트가 막힌 것 (위 '친구 들어오게 하기').
  · 리소스팩을 받다가 실패 → 서버 창에 labadmin pack 으로 상태 확인. config.yml 의 pack: public_host 에
    친구가 접속하는 주소(공인 IP 나 도메인)를 적어 보세요.
  · 메모리는 PC 에 맞춰 자동으로 정합니다. 바꾸려면 start.ps1 을 메모장으로 열어 $Memory = '' 를
    $Memory = '6G' 처럼 고치세요.
  · "Unsupported Java" / "UnsupportedClassVersionError" → start.bat 이 받은 runtime 폴더를 지우고 다시 실행
  · 무언가 이상할 때 → 서버 창에 labadmin selftest 를 입력하면 1분쯤 스스로 점검하고 결과를 알려 줍니다.
  · 미궁 월드를 처음부터 → 서버를 끄고 world/dimensions/minecraft/labyrinth_world 폴더를
    지운 뒤 켜세요. 플레이어 레벨·장비·칭호는 그대로입니다. (원래 world 는 건드리지 않습니다)
  · 플러그인을 바꿀 때는 /reload 대신 서버를 껐다 켜세요.
  · 마을 상태 점검 → 서버 창에 labadmin village selftest (블록·NPC·입구가 제자리인지), labadmin village info.
    NPC 나 입구가 엉뚱한 곳에 있으면 labadmin village apply 로 마을 자리에 다시 놓습니다.


■ 이미 돌리던 서버 업데이트  (예전 판에서 이번 판으로)

  새 판은 마을이 지어진 world 폴더를 함께 줍니다. 미궁 레벨·장비 보관함·칭호·골드는 plugins/Labyrinth 에 있어
  그대로 남고, 인벤토리·엔더 상자는 아래 4번으로 옮깁니다.
  1. 서버를 끕니다 (서버 창에 stop).
  2. 예전 서버 폴더의 world 폴더 이름을 world_old 로 바꿉니다.
  3. 새 zip 의 world 폴더를 예전 서버 폴더에 복사합니다.
     plugins/Labyrinth.jar 도 새 zip 의 것으로 바꿉니다. (plugins/Labyrinth 폴더는 그대로 두세요)
  4. world_old 안의 playerdata · advancements · stats 폴더를 새 world 폴더 안으로 복사합니다.
     (26.x 에서 이 폴더들이 world_old/players/ 아래에 있으면 players 폴더째로 새 world 안에 복사)
  5. 서버를 켭니다. 처음 켤 때 마을 입구·NPC 가 새 마을 자리로 옮겨지고, 예전 월드 좌표에 서 있던 사람은
     처음 들어올 때 마을 광장으로 옮겨집니다 (땅속에 끼지 않게). 예전 석문 입구 기록은 entrance.yml.old 로 남습니다.
  ※ 예전 월드에 지은 건물은 world_old 에 그대로 있습니다. 돌아가려면 서버를 끄고 폴더 이름만 되돌리면 됩니다.
  ※ 관리자가 예전 월드에 따로 세운 NPC(setnpc)는 예전 좌표에 남으니 필요하면 다시 setnpc 하세요.
