■ 켜는 법 (윈도우)

  1. 이 폴더를 원하는 곳에 압축 해제합니다. (바탕화면 등)
  2. 풀린 폴더 안의 start.bat 을 더블클릭합니다.
     - zip 을 연 상태에서 바로 실행하면 안 됩니다. 꼭 압축을 먼저 풀어 주세요.
     - 처음 한 번은 Java 21 과 Paper 서버 파일을 자동으로 내려받습니다. (1~2분)
     - "동의하면 Y 를 입력하고 Enter" 가 나오면 Y 를 입력하고 Enter.
     - Windows 방화벽 창이 뜨면 "허용" 을 누르세요. (친구가 들어오려면 필요)
  3. 창에 "Done" 이 뜨면 서버가 켜진 것입니다.
  4. 마인크래프트 런처에서 버전을 1.21.4 로 고르고 실행
     → 멀티플레이 → 서버 추가 → 주소에 localhost
  5. 처음 접속하면 "서버 리소스팩" 을 받을지 묻습니다. 꼭 "예" 를 누르세요.
     (무기와 아이템 모양이 바뀝니다. 거절하면 보라색/검은색 상자로 보입니다.)
  6. 관리자 명령어를 쓰려면 서버 창에 op 내닉네임 을 입력합니다.
  7. 끌 때는 서버 창에 stop 을 입력합니다. (창을 그냥 닫으면 저장이 안 될 수 있음)

  맥/리눅스는 Java 21 을 설치한 뒤 start.sh 를 실행하세요.

■ 게임 방법

  · 시작의 섬에서 시작합니다. 상자에 용암, 얼음 2개, 묘목, 씨앗, 뼛가루, 횃불이 들어 있어요.
    얼음을 녹인 물과 용암으로 조약돌 생성기를 만드세요. 작업대는 없으니 나무를 베어 만드세요.
  · 처음 들어오면 안내서, 견습생의 검, 증강 파편 3개, 빵을 받습니다.

  [맵]  반지름 약 610m, 떠 있는 섬 약 130개. 섬마다 모습과 나는 재료가 다릅니다.
    시작의 섬엔 꼭 필요한 것만 있으니 다리를 놓아 다른 섬에서 재료를 구하세요.
    하늘 섬은 41가지입니다. 숲, 광산, 목장, 밭, 가문비 숲, 서리 광산, 화산, 작은 요새, 코러스 숲,
    자수정 정동, 산호초, 해저 유적, 정글, 마녀의 늪, 심층 광산 … 섬에는 이름표가 없으니
    땅 블록, 나무, 동물을 보고 알아보세요. 무슨 섬에서 무엇이 나는지는 안내서(/증강 책)의
    '섬 도감' 에 있습니다. 어디에 있는지는 알려 주지 않으니 직접 찾아보세요.
    섬과 섬 사이는 보통 40~50칸, 먼 곳은 80칸쯤 떨어져 있습니다.
    네더 문을 만들어 불을 붙이면 하늘 네더로 갑니다. (아래 [하늘 네더])

  [하늘 네더]
    흑요석 네더 문에 불을 붙이면 공허 위에 네더 섬들이 떠 있는 하늘 네더로 갑니다.
    바닐라 네더처럼 네더의 1칸은 하늘의 8칸입니다. 섬 사이는 다리를 놓아 건넙니다.
    하늘에서는 나지 않거나 아주 조금 나는 재료가 있습니다: 고대 잔해(네더라이트), 위더 해골 머리,
    금 블록과 보루의 보물 상자, 우는 흑요석, 석영, 발광석, 네더 사마귀, 가스트 눈물 …
    섬에는 이름표가 없습니다. 무슨 섬에서 무엇이 나는지는 안내서의 '섬 도감 ⑦' 에 있습니다.
    네더 몹(가스트, 피글린, 마그마 큐브, 블레이즈, 위더 해골 …)이 나옵니다. 문으로 처음 나오는 곳과
    폭 1칸 다리에는 몬스터가 생기지 않고, 가스트 불덩이는 블록을 부수지 않으며 사람도 덜 밉니다.
    네더 몬스터는 문을 지나 하늘로 따라오지 않습니다. 위더는 어디서든 블록을 부수지 않습니다.
    공허 위에서 잡은 몹의 전리품(가스트 눈물, 네더의 별 …)은 잡은 사람 발밑에 떨어집니다.
    공허에 생긴 문 앞에는 흑암 발판이 깔립니다. 네더에서 새로 연 문은 하늘의 시작의 섬 둘레나
    하늘에 직접 세워 둔 문으로만 이어지고, 그 밖이면 "문 건너편이 닫혀 있습니다" 가 뜹니다.
    돌아갈 문을 잃으면 /스폰. 리스폰 정박기를 쓰면 네더에서 다시 태어날 수 있습니다.

  [증강]  실버 29 · 골드 30 · 프리즘 19
    제단은 네 기둥 가운데 보석이 떠 있는 곳입니다. 하늘과 하늘 네더를 합쳐 실버 12 · 골드 8 · 프리즘 4곳.
    등급과 상관없이 맵 전체에 고르게 흩어져 있습니다.
    제단을 우클릭하면 제물 없이 바로 증강 3개 중 하나를 고릅니다.
    제단은 한 번 쓰면 보석이 빛을 잃습니다. (서버 전체 기준, 설정으로 바꿀 수 있음)
    선택지가 마음에 안 들면 무료로 한 번, 그 뒤로는 증강 파편 3개로 다시 뽑기.
    증강권은 손에 들고 우클릭하면 어디서든 그 등급 증강을 고릅니다. (보스가 떨굼)
    /증강 제단 으로 남은 제단 수와 보스 상태를 볼 수 있어요.
    전투 효과(불·둔화·번개, 치명타, 회피, 무기 패시브, 갑옷 세트 효과)는 확률이 아니라
    정해진 횟수마다 터집니다. 예) 공격 5번마다 불태운다, 받는 공격 8번마다 한 번 피한다.

  [무기]  69종 (활 8종 포함)
    작업대에서 만듭니다. 만드는 법은 레시피 책(작업대 왼쪽 초록 책)에 다 나와 있어요.
    재료는 섬마다 나는 것들이라 무기마다 찾아가야 할 섬이 다릅니다.
    다른 무기를 재료로 넣는 강화 조합(13가지)은 같은 종류의 무기만 받습니다. (도끼엔 도끼)
    조합에 증강 파편이 들어가는 것은 수습 마법봉과 프리즘 결정뿐입니다.
    섬 초반 무기는 대부분 스킬 없이 기본 공격(일부는 패시브)으로 싸웁니다. 스킬이 붙은 무기는 55종.
    우클릭 = 스킬,  웅크리기+우클릭 = 두 번째 스킬 (없으면 첫 번째),  웅크리기+좌클릭 = 궁극기 (프리즘 무기)
    활은 그냥 당기면 화살을 쏩니다 (화살 1개만 있으면 줄지 않음).
      웅크리기+당겨 쏘기 = 화살 대신 스킬 (재사용 대기 중이면 그냥 화살),  웅크리기+좌클릭 = 두 번째 스킬
    무기 설명에 [우클릭] 처럼 쓰는 법이 적혀 있어요. F키는 바닐라 그대로 손 바꾸기입니다.
    섬 재료 → 균열 정수 → 보스 → 프리즘 결정 순서로 더 강한 무기를 얻습니다.
    [조합] 모루로 이름을 바꾸거나 마법을 부여한 무기는 레시피 책을 눌러도 칸이 채워지지 않습니다.
           직접 칸에 넣으면 만들어집니다.
    보스·프리즘 무기에는 움직이는 아우라가 있습니다.

  [갑옷]  9세트
    같은 세트를 2개, 4개 입으면 세트 효과 (이동 속도, 체력, 스킬 위력 등).

      서리 · 화염 · 공허   균열 정수로 만든다
      서리 군주 · 화염 거신 · 공허 군주   보스가 떨군다
      프리즘               보스 갑옷 + 프리즘 결정 2개 (+ 다이아몬드, 자수정 블록)
    /갑옷도감 에서 전부 볼 수 있어요.

  [몬스터와 보스]  22종
    밤에 섬에 나오는 몬스터 일부가 이끼 좀비, 수정 크리퍼, 광부 해골 같은 새 몬스터로 바뀝니다.
    폭 1칸짜리 다리 위에는 몬스터가 생기지 않습니다 (팬텀 빼고).
    어딘가에 있는 서리 · 화염 · 공허 균열 섬에는 균열 몬스터가 계속 쏟아지고, 정수를 떨굽니다.
    정수 3가지(2개씩), 증강 파편 2개, 다이아몬드 1개로 프리즘 결정을 만들 수도 있습니다.
    보스 둥지 세 곳에는 보스가 처음부터 자리를 지키고 있습니다.
      서리 군주 · 화염 거신 · 공허의 군주

■ 문제가 생기면

  · 창이 바로 닫히거나 서버가 안 켜짐 → 이 폴더의 start-log.txt 를 메모장으로 열어
    마지막 줄을 확인하세요. 어디서 멈췄는지 적혀 있습니다.
  · localhost 로 접속이 안 됨 → 서버 창에 "Done" 이 떴는지, 마인크래프트 버전이 1.21.4 인지 확인.
    정품 계정이 아닌 런처를 쓰면 server.properties 의 online-mode=true 를 false 로 바꾸고
    서버를 다시 켜야 들어올 수 있습니다. (이때는 아무나 남의 닉네임으로 들어올 수 있으니
    주소는 친구에게만 알려 주세요.)
  · 메모리는 PC 에 맞춰 자동으로 정합니다. 바꾸려면 start.ps1 을 메모장으로 열어 $Memory = '' 를
    $Memory = '6G' 처럼 고치세요.
  · "Unsupported Java" → start.bat 이 받은 runtime 폴더를 지우고 다시 실행
  · 무기가 보라색 상자로 보임 → 멀티플레이 → 서버 편집 → 서버 리소스팩: 사용
  · 아우라가 빛나지 않음 → 셰이더 모드(Iris, OptiFine 셰이더)를 끄면 보입니다.
    리소스팩이 마인크래프트 기본 셰이더를 조금 고쳐 빛나는 픽셀을 그립니다.
  · 맵을 처음부터 다시 → 서버를 끄고 world 폴더를 지운 뒤 켜서
    서버 창에 augadmin buildmap 입력 (빈 공허 월드에 맵을 다시 짓습니다)
    하늘 네더는 world_augsky_nether 폴더에 따로 있어 그대로 남습니다. 함께 새로 하려면 그 폴더도 지우세요.
  · 하늘 네더만 처음부터 다시 → 먼저 모두 하늘로 돌아온 뒤 서버 창에 augadmin 네더 짓기 강제
    (섬을 처음 모습으로 다시 짓습니다. 섬 위에 지은 것과 고친 곳은 사라지고 상자는 다시 채워집니다.)
    또는 서버를 끄고 world_augsky_nether 폴더를 지운 뒤 켜면 새로 지어집니다. 이때 네더에 있던
    사람은 다음 접속 때 시작의 섬에서 시작하고(가진 물건은 그대로), 네더에 두고 온 것은 사라집니다.
  · 하늘 네더를 닫으려면 config.yml 의 nether: enabled: 를 false 로 바꾸고 /증강관리 리로드
  · 플러그인을 바꿀 때는 /reload 대신 서버를 껐다 켜세요 (하늘 네더 월드가 새 플러그인을 써야 합니다)


■ 업데이트

  하늘 네더가 들어간 판은 plugins/AugmentSkyblock.jar 만 바꾸면 됩니다. world 는 그대로 쓰고
  server.properties 도 고칠 것이 없습니다 (allow-nether=false 그대로). 처음 켤 때 world_augsky_nether
  폴더에 하늘 네더가 몇 초 만에 지어집니다. 백업할 때는 이 폴더도 함께 하세요.
  (새로 받은 서버 zip 에는 다 지은 world_augsky_nether 폴더가 들어 있어 바로 쓰입니다.)
  새 섬 배치는 새 world 폴더로만 받을 수 있습니다. 예전 world 를 계속 쓰면 예전 섬 그대로,
  안내 글자와 빛기둥만 사라집니다. 인벤토리를 옮기려면 예전 world/playerdata 폴더를
  새 world 에 복사하세요.
  제단도 마찬가지입니다. 안내서의 제단 수(실버 12 · 골드 8 · 프리즘 4)는 새 world 기준이고,
  예전 world 를 계속 쓰면 하늘 제단은 예전 30곳(실버 16 · 골드 9 · 프리즘 5)이 그대로 남은 채
  하늘 네더 제단 6곳이 더해집니다. 이때는 켤 때 서버 창에 경고가 뜨고 /증강 제단 의 수가 안내서와 다릅니다.
  제단 섬이 없던 예전 판 하늘 네더는 그대로 두고, 모두 하늘로 돌아온 뒤 augadmin 네더 짓기 강제 로
  다시 지으면 제단 섬이 생깁니다.
  새 플러그인을 처음 켜면 안내서 글도 새것(섬 도감 포함)으로 바뀌고, 플레이어가 가진 안내서는
  접속할 때 바뀝니다.
