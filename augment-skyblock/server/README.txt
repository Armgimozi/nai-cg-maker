   증강 스카이블럭 서버  (마인크래프트 자바 에디션 1.21.4)

■ 켜는 법 (윈도우)

  1. 이 폴더를 원하는 곳에 압축 해제합니다. (바탕화면 등)
  2. 풀린 폴더 안의 start.bat 을 더블클릭합니다.
     - zip 을 연 상태에서 바로 실행하면 안 됩니다. 꼭 압축을 먼저 풀어 주세요.
     - 처음 한 번은 Java 21 과 Paper 서버 파일을 자동으로 내려받습니다. (1~2분)
     - "동의하면 Y 를 입력하고 Enter" 가 나오면 Y 를 입력하고 Enter.
     - Windows 방화벽 창이 뜨면 "허용" 을 누르세요. (친구가 들어오려면 필요)
  3. 창에 "Done" 이 뜨면 서버가 켜진 것입니다.
  4. 마인크래프트 런처에서 버전을 1.21.4 로 고르고 실행
     → 멀티플레이 → 서버 추가 → 주소에 localhost
  5. 처음 접속하면 "서버 리소스팩" 을 받을지 묻습니다. 꼭 "예" 를 누르세요.
     (무기와 아이템 모양이 바뀝니다. 거절하면 보라색/검은색 상자로 보입니다.)
  6. 관리자 명령어를 쓰려면 서버 창에 op 내닉네임 을 입력합니다.
  7. 끌 때는 서버 창에 stop 을 입력합니다. (창을 그냥 닫으면 저장이 안 될 수 있음)

  맥/리눅스는 Java 21 을 설치한 뒤 start.sh 를 실행하세요.


■ 친구 들어오게 하기

  [같은 집, 같은 와이파이]
    친구는 서버 주소에 내 PC 의 내부 IP 를 넣습니다.
    내부 IP 확인: 시작 → cmd → ipconfig → "IPv4 주소" (예: 192.168.0.12)

  [다른 집에서]
    방법 A. 공유기 포트포워딩
      공유기 설정에서 25565(게임), 8163(리소스팩) 두 포트를 내 PC 로 열어 줍니다.
      친구는 내 공인 IP 로 접속합니다. (네이버에 "내 아이피" 검색)
    방법 B. playit.gg 같은 터널 프로그램
      게임 포트(25565)만 열리므로 리소스팩을 못 받습니다. 이때는
      plugins/AugmentSkyblock/config.yml 의 resource-pack: url: 에
      리소스팩 zip 을 올린 인터넷 주소를 적어 주세요. (아래 '리소스팩' 참고)

  ※ server.properties 의 online-mode=true 라서 정품 계정만 들어올 수 있습니다.
  ※ 기본으로 PvP 가 꺼져 있습니다(협동). 켜려면 server.properties 의 pvp=true.


■ 게임 방법

  · 시작의 섬에서 시작합니다. 상자에 용암, 얼음, 묘목 등이 들어 있어요.
    얼음을 녹인 물과 용암으로 조약돌 생성기를 만드세요.
  · 처음 들어오면 안내서, 견습생의 검, 증강 파편 3개, 빵을 받습니다.

  [맵]  반지름 약 380m, 떠 있는 섬 86개
    가운데 초원, 서쪽 서리, 동북쪽 화염, 북서쪽 공허, 남쪽 바다 지역.
    지역마다 나오는 재료가 다릅니다 (서리: 얼음·청금석, 화염: 네더 재료·블레이즈 요새,
    공허: 엔드 돌·자수정, 바다: 프리즈머린·구리). 다리를 놓아 넓혀 가세요.

  [증강]  실버 29 · 골드 31 · 프리즘 18
    하늘로 솟은 빛기둥이 제단입니다.
      흰 빛기둥     실버 제단 16곳 (가운데 근처)
      노란 빛기둥   골드 제단 9곳 (중간)
      무지개 빛기둥 프리즘 제단 5곳 (맵 끝자락)
    제단을 우클릭하면 제물 없이 바로 증강 3개 중 하나를 고릅니다.
    제단은 한 번 쓰면 힘을 잃고 빛기둥이 꺼집니다. (서버 전체 기준, 설정으로 바꿀 수 있음)
    선택지가 마음에 안 들면 무료로 한 번, 그 뒤로는 증강 파편 3개로 다시 뽑기.
    증강권은 손에 들고 우클릭하면 어디서든 그 등급 증강을 고릅니다. (보스가 떨굼)
    /증강 제단 으로 아직 남은 가까운 제단과 보스 둥지 위치를 볼 수 있어요.
    전투 효과(불·둔화·번개, 치명타, 회피, 무기 패시브, 갑옷 세트 효과)는 확률이 아니라
    정해진 횟수마다 터집니다. 예) 공격 5번마다 불태운다, 받는 공격 8번마다 한 번 피한다.

  [죽으면]
    가진 아이템을 떨어뜨립니다. 공허에 떨어지면 되찾을 수 없어요.
    아래 증강을 얻으면 죽어도 지킬 수 있습니다.
      실버  단단한 주머니  핫바 왼쪽 3칸 (겹치면 6칸, 9칸)
      실버  무기 수호      새 무기 69종 전부
      골드  갑옷 결속      입은 갑옷과 왼손
      골드  보물 결속      파편, 정수, 결정, 증강권
      골드  경험 보존      경험치 레벨
      프리즘 영혼 결속     전부

  [무기]  69종 (활 8종 포함)
    작업대에서 만듭니다. 만드는 법은 레시피 책(작업대 왼쪽 초록 책)에 다 나와 있어요.
    섬 초반 무기는 대부분 스킬 없이 기본 공격(일부는 패시브)으로 싸웁니다. 스킬이 붙은 무기는 55종.
    우클릭 = 스킬,  웅크리기+우클릭 = 두 번째 스킬 (없으면 첫 번째),  웅크리기+좌클릭 = 궁극기 (프리즘 무기)
    활은 그냥 당기면 화살을 쏩니다 (화살 1개만 있으면 줄지 않음).
      웅크리기+당겨 쏘기 = 화살 대신 스킬 (재사용 대기 중이면 그냥 화살),  웅크리기+좌클릭 = 두 번째 스킬
    무기 설명에 [우클릭] 처럼 쓰는 법이 적혀 있어요. F키는 바닐라 그대로 손 바꾸기입니다.
    섬 재료 → 균열 정수 → 보스 → 프리즘 결정 순서로 더 강한 무기를 얻습니다.
    보스·프리즘 무기에는 움직이는 아우라가 있습니다.

  [갑옷]  9세트
    같은 세트를 2개, 4개 입으면 세트 효과 (이동 속도, 체력, 스킬 위력 등).
      개척자 · 광부        섬 재료로 만든다
      서리 · 화염 · 공허   균열 정수로 만든다
      서리 군주 · 화염 거신 · 공허 군주   보스가 떨군다
      프리즘               보스 갑옷 + 프리즘 결정
    /갑옷도감 에서 전부 볼 수 있어요.

  [몬스터와 보스]  22종
    밤에 섬에 나오는 몬스터 일부가 이끼 좀비, 수정 크리퍼, 광부 해골 같은 새 몬스터로 바뀝니다.
    서리 · 화염 · 공허 지역 끝의 균열 섬에는 균열 몬스터가 계속 쏟아지고, 정수를 떨굽니다.
    균열 너머 둥지에는 보스가 처음부터 자리를 지키고 있습니다.
      서리 군주 · 화염 거신 · 공허의 군주
    쓰러뜨리면 30분 뒤 둥지에서 다시 깨어납니다.
    보스 보상(프리즘 결정, 증강권, 보스 무기와 갑옷)은 함께 싸운 친구 모두가 각자 받습니다.

  [명령어]
    /증강          내 증강 보기
    /증강 도감     모든 증강 보기
    /증강 선택     고르다 만 선택지 다시 열기
    /증강 제단     남은 제단과 보스 둥지 위치
    /증강 책       안내서 다시 받기
    /무기도감      모든 무기 보기
    /갑옷도감      모든 갑옷 세트 보기
    /스폰          시작의 섬으로 이동

  [관리자 명령어]  /증강관리
    무기 <id>, 아이템 <id> [개수], 갑옷 <세트> [부위], 증강 추가/제거/초기화 <플레이어> <id>,
    선택지 <플레이어> <등급>, 소환 <몬스터id>, 제단 <등급>, 균열 <id>, 둥지 <보스id>,
    맵생성, 리로드, 리소스팩, 정보


■ 설정 바꾸기

  plugins/AugmentSkyblock/ 폴더 (서버를 한 번 켜면 생깁니다)
    config.yml    제단(일회용 방식, 다시 뽑기), 보스 부활 시간, 파편 확률, 광석 생성기, 리소스팩
                  altar: single-use: global(서버 전체 한 번) / player(사람마다 한 번) / off(무제한)
    augments.yml  증강 목록         weapons.yml  무기 목록
    armor.yml     갑옷 세트         skills.yml   스킬 목록
    mobs.yml      몬스터, 균열, 보스  items.yml    파편/결정/증강권/정수
  고친 뒤 게임 안에서 /증강관리 리로드
  예전 판에서 올린 서버는 처음 켤 때 config.yml 을 뺀 yml 6개를 old-content-v<예전 판> 폴더
  (v2 서버면 old-content-v2)로 옮겨 두고 새로 꺼냅니다 (config.yml 은 안내서 글만 바뀜).
  고친 내용이 있었다면 그 폴더에서 옮겨 오세요.


■ 리소스팩

  플러그인이 8163 포트로 리소스팩을 직접 보내 줍니다.
  터널 등으로 이 포트를 못 열 때는 AugmentSkyblock-pack.zip 을 인터넷에 올리고
  config.yml 의 resource-pack: url: 에 그 주소를 적으세요.
  예) GitHub 에 올린 파일의 raw 주소


■ 문제가 생기면

  · 창이 바로 닫히거나 서버가 안 켜짐 → 이 폴더의 start-log.txt 를 메모장으로 열어
    마지막 줄을 확인하세요. 어디서 멈췄는지 적혀 있습니다.
  · localhost 로 접속이 안 됨 → 서버 창에 "Done" 이 떴는지, 마인크래프트 버전이 1.21.4 인지 확인.
    정품 계정이 아닌 런처를 쓰면 server.properties 의 online-mode=true 를 false 로 바꾸고
    서버를 다시 켜야 들어올 수 있습니다. (이때는 아무나 남의 닉네임으로 들어올 수 있으니
    주소는 친구에게만 알려 주세요.)
  · 메모리는 PC 에 맞춰 자동으로 정합니다. 바꾸려면 start.ps1 을 메모장으로 열어 $Memory = '' 를
    $Memory = '6G' 처럼 고치세요.
  · "Unsupported Java" → start.bat 이 받은 runtime 폴더를 지우고 다시 실행
  · 무기가 보라색 상자로 보임 → 멀티플레이 → 서버 편집 → 서버 리소스팩: 사용
  · 아우라가 빛나지 않음 → 셰이더 모드(Iris, OptiFine 셰이더)를 끄면 보입니다.
    리소스팩이 마인크래프트 기본 셰이더를 조금 고쳐 빛나는 픽셀을 그립니다.
  · 맵을 처음부터 다시 → 서버를 끄고 world 폴더를 지운 뒤 켜서
    서버 창에 augadmin buildmap 입력 (빈 공허 월드에 맵을 다시 짓습니다)
