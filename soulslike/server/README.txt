식은 가마 (가제) — 혼자 하는 소울류 마인크래프트 서버
================================================================

지금 판: M0 (기반 점검판). 아직 지도와 적이 없고, 시험 방에서
스태미나와 구르기, 죽음 화면만 해 볼 수 있다.


■ 켜는 법 (윈도우)

1. zip 을 마우스 오른쪽 버튼으로 눌러 "압축 풀기" 를 한다.
2. 풀린 폴더 안의 start.bat 을 더블클릭한다.
   - 처음 한 번은 Java 21 과 Paper 1.21.11 을 자동으로 받는다 (100MB 정도).
   - EULA 동의를 물으면 Y 를 입력하고 Enter.
3. 창에 "Done" 이 나오면 마인크래프트 자바 에디션 1.21.11 을 켜고
   멀티플레이 → 직접 연결 → localhost 로 들어간다.
4. 리소스팩을 받겠냐고 물으면 "예". 받지 않으면 들어갈 수 없다.
5. 끌 때는 서버 창에 stop 을 입력한다.

맥/리눅스는 Java 21 을 설치한 뒤 start.sh 를 실행한다.


■ 조작 (M0)

  달리기          스태미나가 준다. 다 쓰면 잠깐 달릴 수 없다.
  F (손 바꾸기)    구르기. 누르고 있는 방향키 쪽으로 구른다.
                   구르는 처음 순간에는 맞지 않는다.

  죽으면 화면에 YOU DIED 가 뜬다.


■ 문제가 생기면

  - 창이 바로 닫히거나 빨간 글이 나오면 start-log.txt 와
    logs\latest.log 를 보내 준다.
  - "FAILED TO BIND TO PORT" 가 보이면 서버가 이미 하나 켜져 있다.
