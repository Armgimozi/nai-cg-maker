   마인크래프트 자바 에디션 1.21.11 / Paper 1.21.11 빌드 132
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

현재 버전: M0 (기초 시험판)
  아직 지도, 적, 보스, 에스트, 술법이 없습니다. 시험 방 하나에서
  스태미나, 구르기, 사망 화면, 출신과 레벨 업이 제대로 동작하는지 확인하는 버전입니다.


■ 서버 켜기 (윈도우)

  1. zip 파일을 마우스 오른쪽 버튼으로 눌러 "압축 풀기"를 하세요.
     zip 파일을 연 채로 start.bat을 실행하면 서버가 켜지지 않습니다.
  2. 압축을 푼 폴더 안의 start.bat을 더블클릭하세요.
     - 처음 한 번은 Java 21과 Paper 서버 파일을 이 폴더에 내려받습니다 (합쳐서 100MB 정도).
       Paper는 1.21.11 빌드 132로 고정되어 있고, 받은 뒤 sha256으로 올바른 파일인지 확인합니다.
     - "동의하면 Y를 입력하고 Enter를 누르세요"가 나오면 Y를 입력하고 Enter를 누르세요. (마인크래프트 EULA)
     - Windows 방화벽 창이 뜨면 "허용"을 누르세요. 혼자 할 때는 "취소"해도 됩니다.
  3. 창에 "Done"이 나오면 서버가 켜진 것입니다.
     처음 켤 때는 마인크래프트 서버 파일을 한 번 더 받고 세계를 만드느라 1~2분 걸립니다.
  4. 서버를 끌 때는 서버 창에 stop을 입력하세요. 창을 그냥 닫으면 저장되지 않을 수 있습니다.

  맥/리눅스: 터미널에서 이 폴더로 이동해 ./start.sh를 실행하세요.
  Java 21이 없으면 Temurin 21을 이 폴더의 runtime에 내려받습니다.


■ 접속하기 (혼자, 같은 PC)

  1. 마인크래프트 런처에서 버전을 1.21.11로 고르고 실행하세요. 모드는 필요 없습니다.
  2. 멀티플레이 → 직접 연결 (또는 서버 추가) → 주소에 localhost를 입력하세요.
  3. 리소스 팩을 받을지 물으면 "예"를 누르세요. 이 서버는 전용 리소스 팩이 있어야 접속할 수 있습니다.
  4. 세계를 만드는 동안 접속하면 "세계를 만드는 중입니다"라는 안내와 함께 접속이 거절됩니다.
     1~2분 뒤 다시 접속하세요.
  5. 관리자 명령어를 쓰려면 서버 창에 op <닉네임>을 입력하세요.

  ※ online-mode=true라서 정품 계정으로만 접속할 수 있습니다.


■ 조작 (M0)

  바닐라 키를 그대로 씁니다. 키 설정을 바꿨다면 바꾼 키를 누르세요.

  달리기 (Ctrl / W 두 번)   스태미나를 씁니다. 화면 왼쪽 위의 초록 막대가 스태미나입니다.
                            다 쓰면 어느 정도 찰 때까지 달릴 수 없습니다.
  웅크리기 키 짧게          구르기. 웅크리기 키를 짧게 눌렀다 떼면 누르고 있는 WASD 방향으로 구릅니다.
                            누르고 있으면 그냥 웅크리기입니다. 방향키 없이 누르면 뒤로 물러섭니다.
                            구르기 처음 몇 틱 동안은 맞지 않습니다. 낙하 피해는 피하지 못합니다.
                            공중, 물속, 사다리, 탈것 위에서는 구를 수 없습니다.
                            스태미나를 쓰고, 장비가 무거우면 구르기가 느려집니다.
                            (웅크리기를 "전환"으로 쓰는 분은 config.yml의 controls.roll-key를 f로 바꾸세요)
  F (손 바꾸기)             패링. 왼손에 든 것으로 쳐냅니다. 패링 단검과 소형 방패는 판정이 넉넉하고
                            중형 방패는 보통이며, 대형 방패와 빈 왼손으로는 패링할 수 없습니다.
                            적을 쳐내는 판정과 치명타는 아직 없습니다.

  처음 접속한 사람이 세계의 난이도 (4단계)와 PvP 켬/끔을 고르고, 사람마다 출신 (6가지)을 고릅니다.
    난이도는 적의 세기입니다. 쉬움 (받는 피해 x0.7, 적 HP x0.8), 보통, 어려움 (x1.25, x1.2),
    아주 어려움 (x1.5, x1.4). 마인크래프트 자체 난이도는 늘 보통입니다.
    창을 닫으면 (나중에 정하기) 우선 보통, PvP 끔으로 시작하고, 그 사람이 다시 접속하거나
    화톳불에서 쉴 때 다시 묻습니다.
    나중에 접속한 사람은 "세계 설정: 보통, PvP 끔" 같은 안내를 봅니다. 관리자는 /souls settings로 바꿀 수 있습니다.
  출신마다 능력치 여섯과 시작 아이템이 다릅니다. 도적은 만능 열쇠를, 궁수는 단궁과 화살 32발
  (바닐라 활처럼 당겨 쏩니다)을 들고 시작합니다.
    출신 창을 닫으면 출신 없이 시작 지점 주변만 걸을 수 있습니다. 웅크리기 키를 짧게 누르면 창이 다시 뜹니다.
    레벨을 하나도 올리지 않았다면 화톳불 메뉴의 "출신 변경"으로 한 번 다시 고를 수 있습니다.
  시험 방 시작 지점에서 동쪽으로 여섯 칸 떨어진 화톳불 (모닥불)을 우클릭하면 휴식하고,
  화톳불 메뉴에서 레벨 업 (소울로 능력치를 한 점씩 올립니다)과 능력치 창을 열 수 있습니다.
  /stats로도 능력치 창을 볼 수 있습니다.
  적이 아직 없어서 소울은 관리자 명령어 /souls souls <닉네임> add <수>로 받습니다.
  지금 적용되는 능력치 효과:
    생명력 (최대 HP, 방어력), 정신력 (마법 방어력. 최대 마나는 막대 길이만 바뀝니다),
    지구력 (최대 스태미나, 스태미나 회복), 근력 (공격력, 장비 중량 한도), 민첩 (이동 속도, 공격 속도),
    지력 (해로운 효과와 불에 타는 시간이 짧아집니다. 술법 위력은 술법이 추가될 때까지 숫자로만 보입니다).

  HP는 저절로 차지 않습니다.
  죽으면 화면 가운데, 버튼 바로 위에 새빨간 YOU DIED가 뜹니다.
  "다시 일어서기"를 누르면 시험 방에서 다시 시작하고, 가진 아이템과 소울은 잃지 않습니다.

  시험 방
    - 남쪽 벽 앞에서 북쪽을 보고 시작합니다.
    - 바닥의 짙은 길은 구르기 연습용 길입니다. 가장자리 눈금이 2칸마다 있어 구른 거리를 잴 수 있습니다.
    - 북서쪽 모서리의 6칸 높이 턱 (사다리로 올라갑니다)은 낙하 시험용입니다.

  에스트는 바닐라 물약처럼 단축 슬롯에 두고 우클릭을 누르고 있으면 마십니다 (M1부터).
  술법과 화톳불 이동은 이후 버전에 추가됩니다.


■ 관리자 명령어 (op)

  /souls check              서버 점검 (데이터팩, 바이옴, 난이도, 게임 규칙, 시험 방, 리소스 팩, 글리프)
  /souls tp <장소>          room (시험 방), lane (구르기 길), ledge (턱 위), lobby (로비)
  /souls build room         시험 방을 지우고 다시 짓습니다
  /souls pack               리소스 팩 상태 (SHA-1, 주소, 자체 확인 결과)
  /souls pack resend        리소스 팩을 다시 보냅니다
  /souls perf               기능별 틱 시간
  /souls reload             설정, 글리프, 콘텐츠를 다시 불러옵니다
  /souls settings           세계 설정 창 (난이도, PvP)
  /souls settings difficulty <easy|normal|hard|very_hard>
  /souls settings pvp <on|off>
  /souls origin reset <닉네임> [keep-items]   출신을 초기화하고 출신 창을 다시 띄웁니다
  /souls souls <닉네임> set|add <수>          보유 소울을 정하거나 더합니다


■ 설정

  plugins/Soulslike/config.yml   난이도 배율, 능력치 곡선, 레벨 비용, 구르기 키, 스태미나·구르기 수치, 리소스 팩 주소
  (서버를 한 번 켜야 생깁니다. 고친 뒤에는 /souls reload를 입력하거나 서버를 다시 켜세요)
  게임 안 문구는 한국어와 영어가 있고, 접속한 사람의 게임 언어로 보입니다 (한국어가 아니면 영어).
  문구는 플러그인과 리소스 팩 안에 있어서 서버 폴더에서는 고칠 수 없습니다.

  server.properties, bukkit.yml, spigot.yml, config/paper-global.yml은 이 서버에 맞춰 둔 설정입니다.
    - 난이도는 normal이어야 합니다. 플러그인이 켜질 때 확인하고 다르면 바꿉니다.
    - 쓰지 않는 네더와 디 엔드는 불러오지 않습니다.
    - 최대 HP 상한을 2048로 올립니다 (spigot.yml). 낮으면 큰 체력 값이 잘립니다.
    - 게임 난이도와 PvP는 처음 접속한 사람이 창에서 고릅니다. 관리자는 /souls settings로 바꿀 수 있습니다.


■ 리소스 팩

  리소스 팩은 인터넷 주소 (raw.githubusercontent.com)에서 받습니다. 파일 이름이 팩 내용의 SHA-1입니다.
  서버가 켜질 때 그 주소에서 팩을 받아 확인하고, 받지 못하거나 내용이 다르면 서버 창에 빨간 글로 알린 뒤
  팩을 "선택"으로 보냅니다. 이때는 팩 없이도 접속할 수 있지만 스태미나 막대와 사망 화면 글자가
  제대로 보이지 않습니다.

  팩을 아직 올리지 않았는데 이 PC에서 혼자 해 보려면 config.yml의 pack을 이렇게 바꾸세요.
      url: "http://127.0.0.1:8163/{sha1}.zip"
      serve-port: 8163
  (친구가 다른 PC에서 접속할 때는 쓰지 마세요. 원래 값으로 되돌리면 됩니다)


■ 친구와 함께 할 때 (되는 만큼만)

  혼자 하는 게임이라 수치는 1인 기준입니다. PvP는 처음 고른 설정을 따릅니다 (기본은 끔).
  PvP를 켜면 플레이어끼리 공격할 수 있습니다. 화톳불 메뉴나 시작 창을 띄운 사람은 맞지 않습니다.
  playit.gg 같은 터널로 25565 포트만 열면 됩니다. 리소스 팩은 인터넷 주소에서 받으므로 따로 열 포트가 없습니다.


■ 처음부터 다시 하기

  서버를 끄고 souls_world 폴더를 지운 뒤 다시 켜면 게임 세계를 새로 만듭니다.
  로비 세계는 world 폴더입니다.


■ 문제가 생기면

  - 창이 바로 닫히거나 빨간 글이 나오면 start-log.txt와 logs\latest.log를 보내 주세요.
  - "FAILED TO BIND TO PORT"가 보이면 서버가 이미 하나 켜져 있는 것입니다. 다른 서버 창을 닫으세요.
  - Paper를 받지 못하면 VPN을 켜고 다시 실행하거나, https://papermc.io/downloads/all 에서
    1.21.11의 빌드 132를 받아 이 폴더에 paper.jar라는 이름으로 넣으세요. 다른 빌드는 다시 받게 됩니다.
  - 바닐라 1.21.11이 아닌 버전으로 접속하면 리소스 팩이 맞지 않습니다.
