   스퀘어 소울 (Square Soul)  —  혼자 하는 소울류 서버
   마인크래프트 자바 에디션 1.21.11 / Paper 1.21.11 빌드 132
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

지금 판: M0 (기반 점검판)
  아직 지도·적·보스·에스트·마법이 없다. 시험 방 하나에서
  스태미나, 구르기, 사망 화면이 제대로 도는지만 본다.


■ 켜는 법 (윈도우)

  1. zip 을 마우스 오른쪽 버튼으로 눌러 "압축 풀기" 를 한다.
     zip 을 연 채로 start.bat 을 누르면 켜지지 않는다.
  2. 풀린 폴더 안의 start.bat 을 더블클릭한다.
     - 처음 한 번은 Java 21 과 Paper 서버 파일을 이 폴더에 받는다 (합쳐서 100MB 정도).
       Paper 는 1.21.11 빌드 132 로 고정되어 있고, 받은 뒤 sha256 으로 맞는 파일인지 확인한다.
     - "동의하면 Y 를 입력" 이 나오면 Y 를 입력하고 Enter. (마인크래프트 EULA)
     - Windows 방화벽 창이 뜨면 "허용". 혼자 할 때는 "취소" 해도 된다.
  3. 창에 "Done" 이 나오면 켜진 것이다.
     처음 켤 때는 마인크래프트 서버 파일을 한 번 더 받고 세계를 짓느라 1~2분 걸린다.
  4. 끌 때는 서버 창에 stop 을 입력한다. 창을 그냥 닫으면 저장이 안 될 수 있다.

  맥/리눅스: 터미널에서 이 폴더로 가 ./start.sh 를 실행한다.
  Java 21 이 없으면 Temurin 21 을 이 폴더의 runtime 에 받는다.


■ 들어가기 (혼자, 같은 PC)

  1. 마인크래프트 런처에서 버전을 1.21.11 로 고르고 실행한다. 모드는 필요 없다.
  2. 멀티플레이 → 직접 연결 (또는 서버 추가) → 주소에 localhost
  3. 리소스팩을 받겠냐고 물으면 "예". 이 서버는 전용 리소스팩이 있어야 들어갈 수 있다.
  4. 세계를 짓는 동안 들어가면 "세계를 짓는 중이다" 로 거절된다. 잠시 뒤 다시 들어간다.
  5. 관리자 명령어를 쓰려면 서버 창에 op 내닉네임 을 입력한다.

  ※ online-mode=true 라 정품 계정이어야 들어갈 수 있다.


■ 조작 (M0)

  바닐라 키 그대로 쓴다. 키를 바꿨다면 바꾼 키를 누른다.

  달리기 (Ctrl / W 두 번)   스태미나를 쓴다. 경험치 막대 자리가 스태미나 막대다.
                            다 쓰면 어느 정도 찰 때까지 달릴 수 없다.
  웅크리기 키 짧게          구르기. 웅크리기 키를 짧게 눌렀다 떼면 누르고 있는 WASD 쪽으로 구른다.
                            누르고 있으면 그냥 웅크리기다. 방향키 없이 누르면 뒤로 물러선다.
                            구르기 처음 몇 틱은 맞지 않는다. 낙하 피해는 피하지 못한다.
                            공중, 물속, 사다리, 탈것 위에서는 구르지 못한다.
                            스태미나를 쓴다. 장비가 무거우면 구르기가 느려진다.
                            (웅크리기를 "전환" 으로 쓰면 config.yml 의 controls.roll-key 를 f 로)
  F (손 바꾸기)             무기 기술 자리 (아직 아무것도 하지 않는다)

  처음 들어온 사람은 세계의 난이도 (넷) 와 PvP 켬/끔을 고르고, 사람마다 출신 (여섯) 을 고른다.
  출신마다 능력치 여섯과 시작 아이템이 다르다. 도적은 만능 열쇠를 들고 시작한다.
  시험 방 시작 자리 동쪽 여섯 칸의 화톳불 (캠프파이어) 을 오른쪽 클릭하면 쉬고,
  휴식 창에서 레벨 올리기 (소울로 능력치 한 점씩) 와 능력치 창을 연다. /stats 도 능력치 창이다.

  체력은 저절로 차지 않는다.
  죽으면 화면 가로 가운데, 단추 바로 위에 새빨간 YOU DIED 가 뜬다. "일어선다" 를 누르면 시험 방에서 다시 선다.
  가진 것은 잃지 않는다.

  시험 방
    - 남쪽 벽 앞에서 북쪽을 보고 선다.
    - 바닥의 짙은 길은 구르기 길이다. 가장자리 눈금이 2칸마다 있어 구른 거리를 잴 수 있다.
    - 북서쪽 모서리의 6칸 턱 (사다리로 오른다) 은 낙하 시험 자리다.

  에스트는 바닐라 물약처럼 단축 슬롯에 두고 우클릭을 누르고 있으면 마신다 (M1 부터).
  마법과 화톳불 이동은 나중 판에 들어온다.


■ 관리자 명령어 (op)

  /souls check              서버 점검 (데이터팩, 바이옴, 난이도, 게임 규칙, 시험 방, 리소스팩, 그림 글자)
  /souls tp <곳>            room (시험 방) · lane (구르기 길) · ledge (턱 위) · lobby (로비)
  /souls build room         시험 방을 지우고 다시 짓는다
  /souls pack               리소스팩 상태 (SHA-1, 주소, 자체 확인 결과)
  /souls pack resend        리소스팩을 다시 보낸다
  /souls perf               체계별 틱 시간
  /souls reload             설정·그림 글자·콘텐츠를 다시 읽는다
  /souls settings           세계 설정 창 (난이도·PvP)
  /souls settings difficulty <easy|normal|hard|very_hard>
  /souls settings pvp <on|off>
  /souls origin reset <이름> [keep-items]   출신을 지우고 출신 창을 다시 띄운다
  /souls souls <이름> set|add <n>           소울을 정한다


■ 설정

  plugins/Soulslike/config.yml   난이도 배율, 능력치 곡선, 레벨 비용, 구르기 키, 스태미나·구르기 수치, 리소스팩 주소
  (서버를 한 번 켜야 생긴다. 고친 뒤 /souls reload 또는 서버를 다시 켠다)
  게임 안 문구는 한국어와 영어가 있고, 접속한 사람의 게임 언어로 보인다 (한국어가 아니면 영어).
  문구는 플러그인과 리소스팩 안에 있어 서버 폴더에서 고치지 않는다.

  server.properties, bukkit.yml, spigot.yml, config/paper-global.yml 은 이 서버에 맞춰 둔 것이다.
    - 난이도는 normal 이어야 한다. 플러그인이 켤 때 확인하고 다르면 바꾼다.
    - 쓰지 않는 네더와 디 엔드는 띄우지 않는다.
    - 최대 HP 상한을 2048 로 올린다 (spigot.yml). 낮으면 큰 체력이 잘린다.
    - 게임 난이도와 PvP 는 처음 들어온 사람이 창에서 고른다. 관리자는 /souls settings 로 바꾼다.


■ 리소스팩

  리소스팩은 인터넷 주소(raw.githubusercontent.com)에서 받는다. 파일 이름이 팩 내용의 SHA-1 이다.
  서버가 켜질 때 그 주소에서 팩을 받아 보고, 못 받거나 내용이 다르면 서버 창에 빨간 글로 알린 뒤
  팩을 "선택" 으로 보낸다. 이때는 팩 없이도 들어가지지만 스태미나 막대와 사망 화면 글자가
  제대로 보이지 않는다.

  팩을 아직 올리지 않았는데 이 PC 에서 혼자 해 보려면 config.yml 의 pack 을 이렇게 바꾼다.
      url: "http://127.0.0.1:8163/{sha1}.zip"
      serve-port: 8163
  (친구가 다른 PC 에서 들어올 때는 쓰지 않는다. 원래 값으로 되돌린다)


■ 친구가 들어올 때 (되는 만큼만)

  혼자 하는 게임이라 수치는 1인 기준이다. PvP 는 없다.
  playit.gg 같은 터널로 25565 포트만 열면 된다. 리소스팩은 인터넷 주소에서 받으므로 따로 열 포트가 없다.


■ 처음부터 다시

  서버를 끄고 souls_world 폴더를 지운 뒤 다시 켜면 게임 세계를 새로 짓는다.
  로비 세계는 world 폴더다.


■ 문제가 생기면

  - 창이 바로 닫히거나 빨간 글이 나오면 start-log.txt 와 logs\latest.log 를 보내 준다.
  - "FAILED TO BIND TO PORT" 가 보이면 서버가 이미 하나 켜져 있다. 다른 서버 창을 닫는다.
  - Paper 를 받지 못하면 VPN 을 켜고 다시 실행하거나, https://papermc.io/downloads/all 에서
    1.21.11 의 빌드 132 를 받아 이 폴더에 paper.jar 로 넣는다. 다른 빌드는 다시 받는다.
  - 바닐라 1.21.11 이 아닌 버전으로 들어가면 리소스팩이 맞지 않는다.


■ 이 폴더의 파일

  start.bat                윈도우 시작 (start.ps1 을 부른다)
  start.ps1                윈도우 시작기 본체 (Java·Paper 받기, 메모리 고르기, EULA)
  start.sh                 맥/리눅스 시작기
  server.properties        서버 설정
  bukkit.yml               디 엔드 끄기
  spigot.yml               최대 HP 상한 올리기
  config/paper-global.yml  네더 끄기
  plugins/Soulslike.jar    플러그인 (리소스팩과 데이터팩이 안에 들어 있다)
